### ✨ New

- **Escape sequences in sent content**: the input field resolves `\r\n`, `\n`, `\r`, `\t` and `\\` automatically.

### 🔧 Improvements

- **WSL terminal start-up**: Windows Terminal is preferred and conhost is the fallback.
- **The WSL distribution starts automatically** when none is running, using the default one.
- **`bridge_command` has a timeout**: WSL commands time out after five seconds instead of hanging.
- **Configuration is saved before an update exits** so nothing is lost.

### 🐛 Fixed

- Quick command edits survive a restart, using the `input` event and a `beforeunload` fallback.
- Automatic reconnect remembers the target port instead of connecting to the first device in the dropdown.
- A failed disconnect resets the frontend state so later actions work.
- Data refreshes after a failed connection later succeeds.
- The baud rate dropdown's active state follows the restored configuration.
- WSL mapping and unmapping failures show a notice.
- WSL quick commands persist across restarts.
