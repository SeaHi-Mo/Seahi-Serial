### ✨ New

- **Automation workflows**: each monitor can have rules that run an action when matching data arrives, such as sending data, toggling DTR or RTS, or saving a log.
- **Workflow conditions support regular expressions**: matching by substring, by regular expression or by exact bytes.
- **WSL monitors share the workflow engine**, so WSL port mapping monitors support the same rules.
- **Extra monitors open with advanced settings expanded**, showing data bits, stop bits, parity, DTR and RTS, and the log directory.
- **Adding a monitor widens the window** when there is not enough room.

### 🔧 Improvements

- **Editing the output no longer blocks data refresh**: data keeps appending, auto-scroll pauses temporarily and resumes when editing ends.
- The port dropdown narrowed by 28 px, from 280 to 252, freeing toolbar space.
- The minimum window width rose to 1047 px so the toolbar never wraps.
- Workflow architecture was optimised with separate read and write threads and a compiled regular expression cache.

### 🐛 Fixed

- Serial data no longer stops refreshing after clicking into the output area.
- A Rust compiler warning was cleared by removing an unused `regex_cache` field.
