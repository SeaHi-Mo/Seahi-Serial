### ✨ New

- **Extra monitors copy the current configuration**: opening an additional monitor copies the user settings of the current one, including baud rate, auto-scroll, line numbers, quick commands and workflow rules, as a deep copy that does not interfere with the original.
- **WSL device status dots**: the device list shows a coloured dot, green when idle, yellow when occupied, red on error, refreshed immediately on connect and disconnect.
- **Two-line WSL device entries**: the model is followed by a subtitle with `VID:PID · SN` so identical models can be told apart.
- **WSL device rows highlight when selected**, with a background and a left accent bar.
- **Auto-scroll resumes when the pointer leaves the output area**: clicking the output area pauses auto-scroll, and moving the pointer out of the monitor area resumes it and clears the leftover cursor, without clicking again.

### 🐛 Fixed

- **WSL path resolution** now matches mapped devices through `idVendor` and `idProduct` in sysfs and reads the USB product name, fixing the failure that left the port column showing "WSL" and hid device names in the dropdown.
- **WSL device list refresh** retries path resolution after mapping and polls every five seconds while the panel is open, so the port column no longer stays on "WSL".
- The device list shows the device name without the `(COMxx)` suffix and the WSL path, instead of the Windows name and COM number.
- The WSL monitor dropdown shows `path (device name)` while expanded and only the path once selected.
- **Density and accessibility**: compact row heights, content-sized columns, neutral grey for a switch in the off state, and a focus ring for keyboard users.
