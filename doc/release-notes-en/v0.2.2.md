### ✨ New

- **Error reporting**: application errors are reported automatically, with Sentry or a self-hosted service as backend.
- **A Cloudflare Workers error collector**: a free, globally deployed service with a web admin interface.
- **Panic hook capture**: Rust panics are reported with thread, stack and location.
- **WSL path conversion** now produces the right format when Windows Terminal starts WSL.

### 🔧 Improvements

- Reporting happens silently and does not affect the user experience.
- Errors are de-duplicated, with identical errors counted rather than stored again.
- Local logs are always written, so problems stay traceable offline.
