### 🔒 Security hardening

- **Stored XSS fixed**: send echo was injected as HTML without escaping; it now uses `textContent`, closing the frontend entry point of a remote code execution chain.
- **`open_url` command injection**: `cmd /C start` is gone, replaced by rundll32 with an allow-list of protocols.
- **The update path was tightened**: the download URL and SHA-256 are verified against a backend cache, and the install path is restricted to a controlled directory, ruling out arbitrary download and execution.
- **Log saving is restricted**: `save_log` may only write to the most recently chosen directory.
- **The error collection service** had an undefined `corsHeaders`, a missing UNIQUE constraint on `error_hash` that broke de-duplication, and now restricts CORS to trusted origins.

### 🐛 Fixed

- **Closing a port could deadlock**: closing, reconnecting or closing the window no longer blocks forever when the read thread is stuck, because the thread join has a timeout.
- **WSL process leak**: a timed-out child process or thread is terminated properly instead of leaving an orphan.
- **`list_wsl_devices` timed out**: timeouts per step were shortened, no elevation is attempted when there are no devices, the frontend fallback timeout was extended, and the WSL panel loads its device list normally.
- **Bare `\r` line endings**: embedded devices such as AT modules that end lines with `\r` are split correctly.
- Loading history renumbers the lines instead of leaving them out of order.
- `addMonitor` no longer fails to widen the window because `size.width` was used instead of `size[0]`.
- Several races were fixed: a crash in the baud rate switch closure, unmapping competing with disconnecting, and unhandled rejections in asynchronous calls.

### ✨ Improvements

- Frontend polling went from 10 ms to 25 ms and the read thread backs off when idle, reducing IPC and CPU cost.
- Backend unit tests were added for `parse_hex_bytes`, `parse_version`, `strip_windows_com_suffix` and `decode_wsl_output`.
