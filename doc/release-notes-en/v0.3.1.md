### ✨ Improvements

- **A dedicated elevation window for WSL device mapping**: when the first mapping needs administrator rights, a separate confirmation window appears instead of relying on a fleeting UAC console, and the "succeeded but reported failure" and "wrongly reported cancel" cases in that flow were fixed.
- **A real terminal emulator**: terminal mode was rebuilt as a real Linux terminal. It recognises device prompts such as `=> `, `# ` and `$ `, the input cursor follows the prompt inline, an empty Enter produces a new line, the fixed bottom input bar is gone, the system input method works, and nothing is echoed locally because the device echoes.

### 🐛 Fixed

- The device change event no longer refreshes the WSL monitor port with the Windows COM list.
- Terminal mode and log editing conflicted: `contenteditable` is disabled on the output area in terminal mode to avoid composed text, vertical writing and browser cursor conflicts, and clearing the log keeps the terminal's current line.
