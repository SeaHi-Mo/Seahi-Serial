### ✨ New

- **ADB debugging**: a new panel detects and lists ADB devices with serial number, status dot and model. Clicking a device opens an interactive `adb shell` PTY rendered by xterm, with ANSI colours, cursor control and multi-column `ls`, plus tab completion, and one click returns to the main view.
- **No ADB download needed**: platform-tools including `adb.exe` ship with the installer, so nothing is downloaded at runtime.
- **The toolbar became icons**: function buttons are now icons that follow the theme colour, and the application name text was removed.
- **Hidden serial log cache**: sessions are cached automatically, keeping the ten most recent with FIFO eviction.

### 🐛 Fixed

- **ADB session size mismatch and garbled output**: new `adb_shell_resize` keeps the PTY size in sync with the container, fixing the misaligned completion and prompt, garbled text and truncated edges caused by the fixed 40×120 layout.
- **The ADB device list flickered and showed placeholders**: it updates incrementally, expresses state with a coloured dot, and refreshes every five seconds while the panel is open.
- **Repeated connections and orphan PTYs**: clicking a device twice is ignored, and a PTY whose session never finished is reclaimed when switching quickly.
