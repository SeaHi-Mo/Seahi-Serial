This release changes one thing: the WSL port mapping list no longer shows built-in peripherals, so devices such as the fingerprint reader and the integrated camera do not occupy the list and the serial port to map is easier to find.

### 🐞 Fixed

**1. Fingerprint reader and cameras appeared in the WSL mapping list**

- Symptom: opening WSL port mapping showed `Goodix fingerprint` and two `Integrated Camera` entries (the built-in camera, plus an IR camera on some machines) among other built-in peripherals.
- Root cause: `usbipd list` lists every USB device on the machine, and the state test also counted the word "shared" inside `Not shared` as connected. The old name filter only covered serial, Bluetooth, network and HID devices.
- Now two more groups are filtered: biometric devices (`fingerprint`, `biometric`) and cameras (`camera`, `webcam`). Filtering is by function word rather than vendor name; Goodix also makes BLE and touch hardware, so filtering by vendor would hide devices users do want to map.

### 🧹 Internal

- The filter list moved out of an inline array into a `WSL_USB_NAME_FILTERS` constant and a pure `wsl_usb_name_is_filtered()` function, with unit tests covering both the entries that must be hidden (including case and spacing variants) and the CH340 / CP210x / FTDI serial devices that must not be filtered.
