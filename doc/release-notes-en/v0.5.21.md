This release completes command-line editing in terminal mode, fixes two problems that made users believe data had been cleared when it had not, and makes virtual serial ports show up in the port list.

### ✨ New

**1. Terminal mode: command line editing like a shell**

- In line-buffer mode, ← → move the cursor, ↑ ↓ walk the local command history, and Backspace / Delete / Home / End all work locally; Enter sends the whole line.
- Arrow keys (including Ctrl / Shift combinations) are no longer sent to the device as escape sequences; an AT module only answers those with garbage.
- Direct mode (the default for WSL panes) is unchanged: keystrokes are sent as-is, nothing is intercepted and no line ending is appended.

**2. Virtual serial ports are listed**

- Port enumeration now takes the whole port set from the registry key `HARDWARE\DEVICEMAP\SERIALCOMM` and uses SetupAPI only to fill in display names. Virtual ports such as ELTIMA and com0com, which are not in the "Ports" device class, never appeared before and can now be selected.

**3. The application works on narrower windows**

- The main window minimum width goes from 1047 to 838, and the automatic width of an added pane from 524 to 419.
- The port dropdown in the toolbar shrinks elastically between 80 and 189 px: on a narrow window it is compressed first so the row is kept, and only wraps when it is already at its minimum. Long names keep the port number at the tail, so `… (COM17)` is never cut off.

### 🐞 Fixed

**4. "Clear content" now really clears the on-disk session cache (issue #22)**

- It used to clear only the view: `%APPDATA%\seahi-serial\log-cache\session-*.log` still held the full output, so users could believe sensitive logs were gone. Clearing now also truncates that pane's cache file and resets its write budget.
- The button tooltip states that the disk cache is cleared as well, and the MCP call `serial_clear` behaves the same way.

**5. Two hazards in port enumeration**

- A non-ASCII port name in the registry caused a panic when slicing the prefix by bytes, and that path runs on every start and refresh.
- An over-long value aborted enumeration early, so every port after it disappeared silently; such an entry is now skipped and enumeration continues.

**6. The control name AI sees is no longer a whole sentence**

- The control registry now prefers `aria-label`, using `title` only as a tooltip. Terminal mode used to rewrite `title` into a full sentence, so the button name shown by `ui_list` became that sentence and changed whenever the mode was toggled.

**7. The WSL panel toolbar adapts too**

- Only serial panes compressed the port box; the WSL panel did not, so it overflowed on narrow windows.

### 🔌 MCP

- `serial_set_display` gains a `lineBuf` parameter and `serial_get_state` reports it; when terminal mode is off the parameter reports `skipped` instead of failing.
- Twenty-eight tool descriptions were rewritten (when to use it, what it does and does not do, what not to confuse it with), reducing total length by 33 percent: the model picks tools more accurately and `tools/list` is smaller.
- Two pitfalls found on real hardware are documented: `ble_refresh_rssi` fails when not connected, and `ble_start_scan` does not accept a duration.

### 🧪 Internal

- 288 backend unit tests, 1991 frontend headless assertions and 94 installer self-tests pass.
- New `clear_log_cache` command; truncation uses a separate write handle, since an append handle has no truncate permission on Windows.
