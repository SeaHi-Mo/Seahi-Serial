This release changes no application behaviour; the work is on the documentation site: the landing page and guides now use real interface screenshots and recordings, English content is filled in, MCP setup documentation is added, and the Cloudflare build is supported. The installer version follows the release.

### ✨ Documentation site

**1. The landing page uses the real interface**

- The product window and feature cards are real screenshots of the running application instead of a DOM imitation.
- The hero and the terminal card include real recordings: scrolling serial logs, terminal input and coloured output. They autoplay, loop and are muted.
- When the system asks for reduced motion, a static frame is shown instead.

**2. Guides rewritten with demonstrations**

- Seven Chinese guides were rewritten in task order, without template-like parallelism or bolding on every line.
- Quick start, serial, terminal, quick commands, ADB and WSL, and Bluetooth pages gained matching screenshots or recordings.
- A new MCP setup guide: enabling the server, connecting a client, the common tool chains, read-only mode and troubleshooting.

**3. English guides completed**

- `/en/guide/` now has eight English pages matching the Chinese ones, with the same sidebar grouping.

**4. Layout and navigation**

- Wide-screen documentation pages use the full width: navigation against the left edge, table of contents against the right, body capped at 60rem.
- The MCP entry in the top bar was removed; MCP content now lives in the guides.

**5. Documentation build and deployment**

- Cloudflare Pages Git builds read the root `package.json` version when `APP_VERSION` is not set.
- When the build environment has no local tags, the version dropdown is generated from remote tags instead of showing only the current version.
- `doc/DEPLOY_CLOUDFLARE.md` documents the Cloudflare Git build configuration.

Application behaviour is identical to v0.5.21.
