This release fixes two things that were plainly visible but never explained: the dropdown menus of five dark themes were semi-transparent, letting the toolbar and log area show through (the words "choose log directory" were readable inside the baud rate list), and setting an unsupported baud rate only returned "parameter error", leaving users with no idea what to change.

### 🐛 Fixed

- **Dark theme dropdown panels were semi-transparent** in the dark variants of the five decorative themes. A 15–18 percent tint meant only for the selected entry in the send history had been merged into the container selector group (`.sel-drop`, `.baud-dropdown`, `.send-hist`, `.send-as-drop`), so the whole panel was painted translucent and the `box-shadow` in the same rule was lost as well. The rules are split again: the container keeps the shadow, only the selected entry gets a fill. The six light themes were already correct and are untouched.
- **Setting an unsupported baud rate returned only "parameter error"**. Windows answers `ERROR_INVALID_PARAMETER(87)` and the serial library passes the system text through, which happens on an onboard or virtual COM1 that only supports up to 115200 when 2000000 is entered. The message now says that this port does not accept 2000000 baud, suggests a USB serial adapter or a rate of 115200 or lower, and appends the original error.

### 🧪 Tests

- One more frontend assertion: the dropdown container background may only be the opaque `var(--surface-1)`. Writing a translucent rgba value fails immediately, so restoring the old declaration turns it red.
