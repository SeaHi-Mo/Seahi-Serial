This release rewrites the automation documentation into per-node reference pages and fixes the packaging failure introduced in the previous version. Behaviour is unchanged from v0.6.0 and no interfaces changed.

### ✨ New

**1. Documentation rewrite**

- The single tutorial page is now four pages: overview, quick start, node reference and common flows.
- The node reference has one page per node, each covering what the node does, how its properties are set and where it is typically used.
- Besides the four serial nodes, the 28 built-in nodes bundled with the app also have individual pages, grouped into common, function, sequence and parser categories.
- The node reference group is collapsed by default in the sidebar and marked with a new badge.

**2. Recorded walkthroughs**

- Key steps in the tutorial now use recorded GIFs of the real interface instead of static screenshots only.
- The landing page automation demo now uses a recording of the real application.

### 🔧 Fixed

**1. Node properties showed "not open" while the port was open**

- The port dropdown of automation nodes reported the port as closed even when it was connected; it now reflects the actual state.

**2. Canvas was rebuilt after collapsing**

- The editor overlay re-flows with the toolbar instead of drifting out of place.
- Flows that were deleted no longer reappear after the section is collapsed.

**3. Installer build failure (v0.6.0)**

- The v0.6.0 pipeline packaged before generating the Node-RED runtime, so the installer build failed. The runtime is now generated before packaging, and rebuilding a tag clears any release with the same name first.

### 📦 Installation

- The installer is not code signed, so Windows SmartScreen may warn about an unknown publisher; this is expected for unsigned builds.
- Verification: see [code signing and installation](https://github.com/SeaHi-Mo/Seahi-Serial/blob/main/doc/SIGNING.md). Releases include `SHA256SUMS.txt` and a cosign keyless signature (`.sigstore.json`).
