# comment

## Purpose

Places a note or a coloured block on the canvas. It never runs and connects to nothing, and is used to group and explain parts of a flow.

## Properties

| Option | How to set it |
|---|---|
| Name | The note text, multiple lines allowed |
| Appearance | Text or block, with adjustable size and colour |

## Typical uses

| Scenario | Approach |
|---|---|
| Group a flow | Put a note above each section describing what it does |
| Record constraints | State the port, baud rate or device model the flow expects |
| Temporary masking | Cover an area that is not being worked on |

Comments do not affect deployment or execution; deleting one changes nothing.
