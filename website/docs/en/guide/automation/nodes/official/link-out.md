# link out

## Purpose

Delivers a message to wherever the `link in` with the same name sits, replacing a long wire on the canvas. The message continues unchanged, just elsewhere.

## Properties

| Option | How to set it |
|---|---|
| Link name | The same name as the target `link in`, or create a new one |
| Scope | By default messages are delivered across the same tab |

## Typical uses

| Scenario | Approach |
|---|---|
| Connect across the canvas | Replace long crossing wires with a link |
| Fan out | Every `link in` with the same name receives a copy |
