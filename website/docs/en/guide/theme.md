# Themes

The **theme style** selector and the light/dark switch in the title bar control the interface colours.

There are 6 styles: Default, Ukiyo-e, Poetic East, Ink Wash, Peach Blossom and Golden Wind. Each has a light and a dark variant, for 12 themes in total.

Switching a theme updates the normal output view, terminal mode, sidebar and controls together. The terminal's 16-colour ANSI palette also comes from the current theme and shares the same colour definitions as the normal output view, so coloured log lines look consistent in both views.

The selected theme is written to the configuration file and restored on the next launch.
