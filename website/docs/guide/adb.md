# ADB 调试

ADB 面板用于调试 Android 设备，不占用本机 COM 口。面板通过安装包自带 `platform-tools` 中的 adb 命令与设备通信，功能包括列出设备、打开交互式 shell 与执行命令。

## 打开面板

点击标题栏中的 ADB 图标进入面板。面板打开后该图标变为「返回到串口调试器」，再次点击或点击标题栏左侧的应用图标均可返回串口页。

面板包含两个区域：顶部设备栏横向排列设备卡片，右端为「刷新」按钮；下方会话区在无会话时显示「选择上方设备开始调试会话」。面板内容在首次打开时创建，之后切换页面复用同一界面；每次返回都会刷新设备列表，并将后台会话的输出轮询间隔恢复为 120ms。

ADB 页面打开期间，标题栏的「打开额外监视器」按钮置灰，悬停提示为「ADB 界面不可用」。

## 使用流程

1. 使用 USB 线连接 Android 设备，并在开发者选项中开启 USB 调试。
2. 点击标题栏的 ADB 图标进入面板，设备列表会自动刷新。
3. 在设备上允许本机进行 USB 调试，卡片状态由 `unauthorized` 变为 `device`。
4. 点击状态为 `device` 的卡片，等待会话区显示终端提示符。
5. 在终端中输入命令，输出显示在同一画布中。
6. 需要切换设备时点击另一张卡片，当前会话会先被关闭并回收。
7. 点击标题栏的 ADB 图标或应用图标返回串口页；后台会话保留，输出轮询降频。

## 设备列表

进入面板时程序立即刷新设备列表；面板打开期间每 5 秒自动刷新一次，因为 ADB 设备不在串口插拔通知的覆盖范围内。也可点击「刷新」手动获取。

每张卡片显示设备型号（无型号时显示序列号）与一个状态点。点击卡片会为该设备建立会话；再次点击同一设备仅将焦点交回已有终端，不会重复连接。点击其它设备时，程序先关闭并回收当前会话，再为新设备建立终端；同一时间只保留一个 ADB 会话。

状态点按 `adb devices -l` 返回的状态着色：

| 状态 | 颜色 | 含义 |
|---|---|---|
| `device` | 绿 | 设备可用 |
| `unauthorized` | 红 | 设备尚未允许 USB 调试，需在设备上确认 |
| `offline` | 橙 | 设备无响应，重新插拔或重启 adb 服务后重试 |
| `no` / `no-permissions` | 红 | 无权限访问该设备 |
| `recovery` / `sideload` / `bootloader` / `connecting` / `authorizing` | 橙 | 设备处于过渡状态 |
| `error` / `failed` / `unknown` | 红 | 状态读取失败 |

列表为空时显示「未检测到 ADB 设备」；adb 不可用时提示检查 adb 是否已安装。

## 打开 shell

点击设备卡片后，会话区创建 xterm 终端，后端在伪终端（PTY）中执行 `adb -s <序列号> shell`。PTY 的环境变量为 `TERM=xterm-256color` 与 `COLORTERM=truecolor`，工作目录为 `C:\`；初始尺寸为 40 行 × 120 列，等待 1.5 秒后开始读取输出。前端收到 PTY 会话 id 后将焦点交给终端，此后按键均写入该 PTY。

打开失败时，终端区域显示一行红色文本「连接设备失败: …」，同时记录失败原因供界面状态使用。终端回滚缓冲保留最近 1000 行，配色固定为深色，不跟随界面主题。

关闭会话的方式是切换到另一台设备：程序结束旧会话的子进程、销毁终端实例，并从后端移除 PTY 会话。离开 ADB 页面不会关闭后台会话，仅将输出轮询间隔由 120ms 调整为 2000ms，返回后恢复。

## 输入与输出

- 按键直接写入 PTY，由设备上的 shell 解释；ADB 面板不提供发送输入框、行缓冲与发送历史，回车由终端发送 `CR`。
- 输出由前端每 120ms 轮询一次并交给 xterm 解析，ANSI 颜色、光标移动与全屏程序均按终端处理；新输出自动滚动至底部。
- 页面隐藏时轮询间隔调整为 2000ms，避免离开面板后仍以高频访问后端。
- 前端取走不及时时，后端 PTY 输出队列最多缓存 512 块，超出后丢弃最旧的块并计数；终端显示一行黄色提示，说明丢弃的块数。
- 终端尺寸由前端按容器实际像素计算列数与行数，并通过 `adb_shell_resize` 同步至后端 PTY。面板隐藏时容器尺寸为 0，此轮不测量也不同步，避免将 shell 缩至 2×2 并破坏缓冲区。
- 粘贴内容通过同一写入命令发送，多行内容一次写入后由设备上的 shell 解析。

## 终端里的操作

- 键盘输入原样写入 PTY：Tab 交给设备 shell 完成补全，方向键、Ctrl 组合键与全屏程序的按键不在本机拦截。
- 终端不维护命令历史，历史由设备侧 shell 的 readline 负责，`↑` 读取的是设备记录的命令。
- 画布可通过滚轮查看最近 1000 行，有新输出时自动回到底部。
- 终端不提供「复制全部」与「保存日志」按钮，内容仅保存在终端缓冲中，关闭程序后不保留。

## 与串口终端的区别

| 项目 | ADB 终端 | 串口分栏的终端模式 |
|---|---|---|
| 输入口径 | 按键原样写入 PTY | 直发或行缓冲两种 |
| 回滚行数 | 1000 行 | 5000 行 |
| 配色 | 固定深色 | 跟随当前主题 |
| 输出轮询 | 可见 120ms、隐藏 2000ms | 可见 25ms、隐藏 500ms |
| 关闭会话 | 切换设备时回收 | 关闭分栏时销毁实例 |
| 会话缓存 | 不写入 log-cache 缓存文件 | 写入 log-cache |

## adb 工具

程序按以下顺序查找 `adb.exe`：

1. 程序目录下的 `platform-tools\adb.exe`；安装包将 `platform-tools` 分发到该位置。
2. 从程序所在目录逐级向上查找 `platform-tools\adb.exe`，用于从开发目录直接运行构建产物的场景。
3. 系统 `PATH` 中的 `adb.exe`。

三处均未找到时，设备列表提示「请检查 adb 是否已安装」。安装时可勾选「将 ADB 工具(platform-tools)添加至系统 PATH」，此后可在终端或脚本中直接调用 `adb`。

程序不提供 adb server 的启停按钮：`adb devices`、`adb shell` 等命令首次执行时由 adb 自行启动常驻服务进程。安装与卸载时，安装器先结束镜像路径位于本应用 `platform-tools` 下的 adb 进程，避免其锁定文件导致升级失败；Android Studio 或其它来源的 adb 不受影响。

常见提示与处理方式：

| 提示 | 原因 | 处理 |
|---|---|---|
| `未找到 adb 可执行文件` | 三处查找均未找到 adb | 重新安装，或将 platform-tools 加入 PATH |
| `adb devices 执行超时` | adb 命令 5 秒内未返回 | adb server 卡住或设备无响应，重启 adb 服务后重试 |
| `未检测到 ADB 设备` | 列表为空或 adb 不可用 | 检查 USB 线、USB 调试开关与设备授权状态 |
| `unauthorized` | 设备尚未允许本机调试 | 在 Android 设备上允许 USB 调试 |
| `offline` | 设备无响应 | 重新插拔设备，或重启 adb 服务后重试 |
| 终端显示 `连接设备失败: …` | `adb shell` 未能建立 | 按红色文本中的原因处理 |
| 终端显示 `已丢弃 N 块输出` | 前端取走不及时 | 停止大量输出的后台命令，或更换输出较少的设备 |

## 说明

- 面板仅提供设备列表与交互式 shell；文件传输与日志抓取不在面板功能范围内。
- 同一时间只维护一个会话，切换设备时旧 shell 会被结束，不在后台保留多个 PTY。
- 终端配色固定为深色，与串口分栏的终端模式不同，不跟随界面主题。
- 查找 adb 时不读取 `ANDROID_HOME` 等环境变量，仅检查上述三处路径。
- 设备列表的 5 秒自动刷新仅在 ADB 页面打开期间运行，离开页面后停止。
