# cmd list

## 作用

发送「快捷指令」面板中维护的条目。节点只保存条目的标识，不保存指令文本；运行期按标识向面板取内容，所以在面板里修改指令后，已部署的流程会跟着使用新内容。

## 属性设置

双击画布上的节点打开属性面板。

| 参数 | 设置方法 |
|---|---|
| 名称 | 画布上显示的文字，只影响可读性；留空显示 `cmd list` |
| 端口 | 下拉选择当前已打开的串口 |
| 指令 | 从快捷指令面板的条目中选择，按组列出；灰色分组标题只作分隔，不能选中 |
| 行尾 | 发送时追加 `CRLF` / `CR` / `LF` / 不加；该条目标记为 HEX 时按字节发送，不加行尾 |

下拉在打开面板时读取当前列表。列表为空时显示「快捷指令列表是空的」，此时需要先在串口面板添加条目。

## 常见用途

| 场景 | 做法 |
|---|---|
| 复用调试指令 | 把面板里调好的指令直接搬进流程，不必在两个地方各维护一份 |
| 统一修改指令 | 指令变更时只改面板，所有引用它的流程一起生效 |
| 组合不同步骤 | 同一流程放多个 `cmd list`，各自选择不同条目 |

## 注意

条目被删除或列表为空时，节点按配置时保存的文本发送，并在状态与 `msg.stale` 上标注该条目已失效，不会静默改成别的指令。

快捷指令的增删改在串口面板完成，节点内不做编辑。
