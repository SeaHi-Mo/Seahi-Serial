# batch

## 作用

把连续的多条消息按条数或时间窗分组成一条，一次交给下游处理。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 分组方式 | 按条数、按时间间隔，或按分组键 |
| 条数 | 收满多少条后输出 |
| 间隔 | 多久输出一次已收到的内容 |
| 输出格式 | 数组或按 `msg.parts` 组织的序列 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 批量写入 | 把逐条到达的数据攒成一批再记录 |
| 降低下游频率 | 高频数据合并后再交给耗时节点 |
| 按窗口统计 | 每隔固定时间输出一段数据做汇总 |

## 注意

时间窗到期时即使不足条数也会输出，下游需要能处理"不满一批"的情况。
