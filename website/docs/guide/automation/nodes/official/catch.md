# catch

## 作用

捕获同一流程内节点抛出的错误，并把错误信息作为消息输出。没有它时，错误只出现在调试面板，流程链会静默中断。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 捕获范围 | 本流程、所有流程，或指定节点 |
| 指定节点 | 选择只捕获哪些节点的错误 |

输出的消息包含 `error.message`（错误说明）与 `error.source`（出错节点）。

## 常见用途

| 场景 | 做法 |
|---|---|
| 统一错误出口 | 接到告警节点或写入日志，出错时留下记录 |
| 出错后恢复 | 结合 `delay` 与 `serial txd` 重发命令，或发送复位指令 |
| 避免流程静默中断 | 至少给关键分支配一个 `catch`，让异常可见 |

## 注意

`catch` 捕获的是节点抛出的错误，不是设备返回的 `ERROR`。设备层面的失败判断要用 [serial request](/guide/automation/nodes/serial-request) 的结果分支。
