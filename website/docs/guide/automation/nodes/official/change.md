# change

## 作用

修改消息的属性：设置新值、替换、删除或移动字段。不需要写代码就能调整消息结构。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 规则 | 每条规则一个动作：设置、更改、删除、移动 |
| 目标属性 | 用点号表示层级，例如 `msg.payload.temp` |
| 值 | 固定值，或来自其他属性、JSONata 表达式 |

多条规则按顺序执行，后面的规则能看到前面改过的结果。

## 常见用途

| 场景 | 做法 |
|---|---|
| 改写发送内容 | 把收到的内容改成要发送的指令 |
| 补充来源标记 | 给 `msg.topic` 赋值，便于下游区分 |
| 清理字段 | 删掉不需要透传的大字段，避免消息变大 |

## 注意

删除不存在的字段不会报错；改名要确认目标属性路径拼写正确，否则会把值写到预期之外的位置。
