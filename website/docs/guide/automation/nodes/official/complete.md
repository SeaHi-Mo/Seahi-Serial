# complete

## 作用

当指定的节点处理完一条消息时触发，无论处理成功还是失败。用于在某个动作结束后接上后续处理。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 监听节点 | 选择一个或多个节点；默认是同一流程内的节点 |
| 范围 | 本流程或所有流程 |

输出的消息包含 `msg.complete` 字段，说明是哪个节点完成的。

## 常见用途

| 场景 | 做法 |
|---|---|
| 串接后续动作 | 在发送完成后触发下一条指令 |
| 统计执行情况 | 计数或记录每次完成的节点与耗时 |
| 与 `catch` 配合 | `complete` 处理正常结束，`catch` 处理异常结束 |

与 `catch` 的区别：`complete` 不管成功失败都会触发，`catch` 只在出错时触发。
