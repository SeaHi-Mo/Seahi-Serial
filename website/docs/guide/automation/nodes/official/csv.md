# csv

## 作用

在 CSV 文本与对象数组之间转换：解析收到的表格文本，或把数组生成 CSV 行。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 转换方向 | 文本转对象，或对象转文本 |
| 列定义 | 每列的名称与类型（字符串 / 数值） |
| 分隔符 | 默认逗号，可改为分号、制表符等 |
| 表头 | 输出时是否带首行表头 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 解析设备报表 | 设备以逗号分隔返回多列数据时拆成字段 |
| 生成批量指令 | 把数组拼成 CSV 交给外部工具或写入日志 |

## 注意

解析时列数必须与列定义一致，否则该行可能被截断。字段中含分隔符时，需要按 CSV 规则添加引号。
