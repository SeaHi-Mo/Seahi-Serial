# debug

## 作用

把消息内容显示在编辑器的调试面板，用于观察流程中间的实际情况。节点本身不改变消息，也不影响流程走向。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 输出 | 选择 `msg.payload`、完整消息对象，或指定某个属性 |
| 名称 | 调试面板里显示的标签，建议写清是哪一段的输出 |
| 输出到 | 调试面板、运行时日志，或两者 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 查看某节点的输出 | 接在节点后面，部署后观察内容与结构 |
| 确认分支走向 | 在每个分支各接一个，看实际命中哪一路 |
| 检查 JSON 结构 | 输出完整消息，展开查看字段名与层级 |

调试节点长期留着会拖慢长流程，稳定后建议移除或改为按需启用。
