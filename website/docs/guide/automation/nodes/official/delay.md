# delay

## 作用

让消息晚一点继续，或限制单位时间内通过的条数。用于控制节奏，避免连续发送把设备刷爆。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 延迟 | 固定时长，或在一个区间内随机 |
| 限速 | 每 N 条间隔指定时间，或按固定速率 |
| 允许覆盖 | 收到新消息时是否立即放行上一条 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 两条指令之间留间隔 | 接在发送之后，让设备有时间处理 |
| 限速 | 批量发送时限制每秒条数 |
| 合并突发 | 配合允许覆盖，只保留最后一条 |

## 注意

延迟期间消息被暂存，流程量大时会累积内存。长时间等待更适合用 [trigger](/guide/automation/nodes/official/trigger) 或 `inject` 的定时触发。
