# exec

## 作用

在运行流程的机器上执行系统命令，并把输出作为消息。用于调用外部工具做格式转换或批量处理。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 命令 | 可执行程序或脚本路径，参数可引用消息字段 |
| 超时 | 命令运行上限，超时后结束进程并报错 |
| 输出 | 一次输出整段，或按行拆成多条消息 |
| 追加输出 | 命令的 stderr 是否一并返回 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 调用外部工具 | 用现成命令行工具做校验、转换或打包 |
| 与本地脚本联动 | 把流程里的数据交给脚本处理，再取回结果 |

## 注意

命令内容来自流程配置，部署前确认来源可信；不要拼接未经校验的外部输入，避免命令注入。命令在后台引擎所在的用户下执行，权限与程序本身一致。
