# function

## 作用

用 JavaScript 处理消息。可以读取、修改 `msg`，也可以返回数组一次性输出多条消息，是最灵活的一个节点。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 代码 | 编辑 `msg` 并用 `return msg;` 返回；返回 `null` 表示丢弃 |
| 输出数量 | 多输出时返回数组，按位置对应输出口 |
| 超时 | 单条消息的处理时限，防止死循环卡住流程 |
| 模块 | 可引入允许列表内的 npm 模块 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 拼接指令 | 按变量组合出带参数的 AT 指令 |
| 计算校验 | 求 CRC、换算数值、拼装报文 |
| 复杂分支 | 条件较多、`switch` 表达不便时用代码判断 |

## 注意

代码在后台引擎里执行，报错会中断该条消息并交给 `catch`。建议处理前后各接一个 `debug`，确认输入输出符合预期。
