# global-config

## 作用

定义一份全局配置，供其他需要共享设置的节点引用。随包的内置节点里用到它的不多，主要用于统一管理同类参数。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 类型 | 选择配置类型，决定可填写的字段 |
| 名称 | 其他节点通过这个名称引用该配置 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 统一参数 | 多个节点共用同一组设置时，改一处即可全部生效 |
| 区分环境 | 为不同设备或现场维护不同的配置节点 |

## 注意

网络类节点（HTTP、MQTT 等）已从随包运行时移除，因此这类依赖 `global-config` 的用法在当前版本不适用。
