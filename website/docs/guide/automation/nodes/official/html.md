# html

## 作用

从 HTML 文本中提取指定元素，或把数据渲染成 HTML 片段。用于处理网页内容或落盘成可读报告。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 操作 | 提取元素，或生成 HTML |
| 选择器 | CSS 选择器，例如 `table tr` 或 `.value` |
| 输出 | 只取文本、保留标签，或输出属性值 |
| 模板 | 生成模式下使用的模板 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 从网页提取字段 | 抓取带 HTML 结构的日志后按选择器取值 |
| 生成报告片段 | 把多条处理结果渲染成表格写入文件 |

## 注意

选择器写错时节点不报错，只是输出空结果。提取前建议先用 `debug` 查看原始 HTML 结构。
