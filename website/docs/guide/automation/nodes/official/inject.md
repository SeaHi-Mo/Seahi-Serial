# inject

## 作用

生成一条消息，作为流程的起点。触发方式有手动点击、定时重复、编辑器启动后执行一次三种。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| `payload` | 选择类型（字符串 / 数字 / 布尔 / JSON / 时间戳 / 日期）并填写值 |
| `topic` | 可选，写入 `msg.topic`，下游可据此区分来源 |
| 重复 | 不重复、按间隔（秒）、按 cron 表达式 |
| 启动时执行一次 | 勾选后在部署完成时触发一次，可设置延迟秒数 |

节点左侧的方形按钮可手动触发一次，用于调试。

## 常见用途

| 场景 | 做法 |
|---|---|
| 手动发一条指令 | 触发一次，观察串口面板的收发 |
| 定时心跳 | 重复间隔设置为发送周期 |
| 按固定时刻执行 | 用 cron 表达式，例如每天某个时间点自检 |

需要"发完等回复"时不要用 inject 反复触发，改用 [serial request](/guide/automation/nodes/serial-request)。
