# join

## 作用

把多条消息合并成一条。与 `split` 相对，用于把分片到达的回复拼回完整内容。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 合并方式 | 数组、字符串、按键聚合 |
| 分隔符 | 字符串合并时使用的连接符 |
| 条数或超时 | 收满指定条数合并，或等待指定时间后合并已收到的部分 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 拼回分片回复 | 接在 `split` 之后，还原成一条完整消息 |
| 汇总批量结果 | 多条处理结果聚成一个数组再统一写日志 |
| 超时兜底 | 设备回复不完整时，到点把已收到的内容先交出去 |

## 注意

超时合并会把"不完整"的结果一并输出。对完整性要求高的场景，应在合并后用 `switch` 检查内容是否齐全。
