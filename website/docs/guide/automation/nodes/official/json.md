# json

## 作用

在 JSON 文本与 JavaScript 对象之间转换：把字符串解析成对象方便取值，或把对象序列化成字符串便于发送。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 转换方向 | 对象转 JSON 字符串，或 JSON 字符串转对象 |
| 输入属性 | 默认 `msg.payload`，也可指定其他字段 |
| 输出方式 | 覆盖原字段，或写入另一个属性 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 解析设备 JSON | 设备返回 JSON 文本时先转换，再用 `switch` 取字段 |
| 构造请求内容 | 把拼好的对象转成字符串交给发送节点 |
| 排查数据结构 | 与 `debug` 配合查看层级与字段名 |

## 注意

内容不是合法 JSON 时会报错，错误交给 `catch` 处理。解析前可以先接 `debug` 确认文本没有多余的换行或前缀字符。
