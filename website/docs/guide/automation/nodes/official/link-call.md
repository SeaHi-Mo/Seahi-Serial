# link call

## 作用

调用同名 `link in` 所在的那段流程，并在处理完成后把结果取回来继续。用于把一段公共处理封装成"子流程"。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 链接名称 | 指向目标 `link in` 的名称 |
| 超时 | 等待返回的时间上限，超时按错误处理 |

被调用的流程需用 `link out` 把结果投递回同名链接。

## 常见用途

| 场景 | 做法 |
|---|---|
| 复用命令拼装 | 多处需要同样的指令格式时集中在一处维护 |
| 统一错误处理 | 把校验逻辑放进一段流程，各处调用 |

## 注意

`link call` 会阻塞本次消息直到返回或超时；被调用的流程不要形成环，否则会一直等到超时。
