# link out

## 作用

把消息投递给同名 `link in` 所在的位置，替代画布上的长连线。消息不会中断，只是换了个地方继续。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 链接名称 | 与目标 `link in` 填同一个名称；也可新建名称 |
| 作用域 | 默认可在同一标签页内跨区域投递 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 跨屏连接 | 流程很长时用链接代替横跨画布的连线 |
| 一处分发多处 | 多个同名 `link in` 会各收到一份消息 |
