# range

## 作用

把一个数值按比例映射到另一个区间，例如把 0–1023 的读数换成 0–100 的百分比。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 输入范围 | 原始数值的最小值与最大值 |
| 输出范围 | 目标区间的最小值与最大值 |
| 取整与夹取 | 可选是否四舍五入、超出范围时是否夹到端点 |
| 输入属性 | 默认取 `msg.payload`，也可指定其他字段 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 读数换算 | 把 ADC 原始值换成电压、温度或百分比 |
| 参数缩放 | 把用户填写的物理量换算成设备需要的寄存器值 |

## 注意

输入超出范围时，未开启夹取会输出超出目标区间的值。对设备下发前建议开启夹取，避免越界参数。
