# rbe

## 作用

只在值发生变化时放行消息，相同值的重复消息被丢弃。用于抑制重复上报。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 属性 | 监控哪个字段，默认 `payload` |
| 模式 | 值变化时通过，或变化且不是空值时通过 |
| 起始值 | 可指定一个初始值，第一次与之相同时也不通过 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 抑制重复读数 | 温度等缓变量只在变化时继续往下走 |
| 过滤状态刷屏 | 接在状态类消息之后，只在状态真正改变时处理 |
| 减少日志量 | 长时间稳定的流程只在变化时记录 |

## 注意

`rbe` 只比较相邻两条消息。中间值跳变再回到原值时仍会放行一次，这是预期行为。
