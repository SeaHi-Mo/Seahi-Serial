# sort

## 作用

对一串消息按某个字段排序，再按顺序输出。处理"一批数据"时使用，单条消息不会触发排序。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 排序键 | 用哪个字段排序，默认 `payload` |
| 顺序 | 升序或降序 |
| 条数上限 | 最多缓存多少条，超过后开始输出 |
| 分组键 | 可按某字段分组，组内分别排序 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 整理采集记录 | 按时间或序号排列后统一输出 |
| 修正乱序到达 | 多路并发采集时按序号还原顺序 |
| 选出极值 | 配合条数上限只保留前几条 |

## 注意

节点会缓存消息直到达到条数上限或触发分组切换，长时间等不到足量消息时不会输出。数量不确定的场景建议配合 `batch` 或 `join` 的超时设置。
