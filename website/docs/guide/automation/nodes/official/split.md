# split

## 作用

把一条消息拆成多条：数组拆元素、字符串按长度或分隔符切分、缓冲区按字节切分。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 拆分对象 | `msg.payload`，或指定其他字段 |
| 拆分方式 | 按数组元素、按固定长度、按分隔符、按字节 |
| 键名 | 拆分数组时，可选把键填入 `msg.parts` 便于后续合并 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 逐行处理多行文本 | 用换行符作分隔符，把设备返回拆成多行 |
| 分批发送 | 把长报文按固定长度切分后逐条下发 |
| 遍历列表 | 把数组拆成多条消息分别处理 |

## 注意

拆出的每条消息都带 `msg.parts`，可用于 `join` 合并回一条。空片段是否保留取决于分隔符设置。
