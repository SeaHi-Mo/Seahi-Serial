# status

## 作用

订阅其他节点的状态变化（例如"已连接""正在发送""发送完成"），并转成普通消息输出，让状态也能参与流程判断。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 监听节点 | 选择一个或多个节点 |
| 状态类型 | 选择要转发的状态；留空表示全部 |

输出的消息包含 `msg.status`，其中有 `text`、`fill` 等字段。

## 常见用途

| 场景 | 做法 |
|---|---|
| 把状态变成事件 | 节点从"发送中"变为"已完成"时触发后续动作 |
| 监控连接状态 | 端口断开时触发提示或重连流程 |
| 汇总运行情况 | 收集多个节点的状态，写入日志 |

## 注意

状态消息频繁变化，直接接 `debug` 会刷屏。通常要配合 `rbe`（只在变化时通过）或 `switch` 做过滤。
