# switch

## 作用

按消息里某个属性的值，把消息送到不同的输出口。相当于流程里的条件分支。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| `property` | 要判断的字段，常用 `payload` 或 `topic` |
| 规则 | 每个输出口一条规则：等于、不等于、包含、正则、数值比较、JSONata、否则 |
| 目标 | 规则里填的值，例如 `OK` |

规则的判断顺序与输出口顺序一致，命中第一条即停止；「否则」匹配所有未命中的消息。

## 常见用途

| 场景 | 做法 |
|---|---|
| 按应答分支 | 判断回复是否包含 `OK` 或 `ERROR`，分别接不同处理 |
| 按来源分流 | 用 `topic` 区分多条指令的回复 |
| 数值区间判断 | 用数值比较把读数分档 |

## 注意

文本匹配区分大小写，且按"包含"判断时子串相同也会命中。需要精确匹配一行时用「等于」或正则。
