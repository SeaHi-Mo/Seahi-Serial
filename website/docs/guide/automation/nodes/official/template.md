# template

## 作用

用模板生成文本，把消息里的变量填进固定格式，常用于拼装指令或生成报文。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 模板 | 正文里用 `{{payload}}` 之类的占位符引用消息字段 |
| 语法 | mustache（默认）或纯文本 |
| 字段 | 引用 `msg` 或 `flow` 上的值 |
| 输出属性 | 默认写回 `msg.payload`，也可指定其他字段 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 拼装带参数的指令 | 把数值填进 `AT+XXX={{payload}}` 这类模板 |
| 生成多行报文 | 模板中直接写换行与固定头部 |
| 生成 HTML 或日志行 | 拼接展示用的字符串 |

## 注意

模板里的换行会原样进入消息；发送前确认行尾设置，避免出现重复的换行。
