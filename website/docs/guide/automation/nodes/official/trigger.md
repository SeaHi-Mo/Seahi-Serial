# trigger

## 作用

收到一条消息后先等一段时间再发出，或在这段时间内收到新消息就重新计时。用于去抖、超时兜底和定时动作。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 延时 | 收到消息后等待多久再发出 |
| 延长计时 | 期间再次收到消息时是否重新开始计时 |
| 超时后再发一条 | 可选择超时后发出第二条消息，用于兜底 |
| 重置 | 可用另一条消息取消待发的定时 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 去抖 | 设备短时间连发多条时只处理最后一条 |
| 超时兜底 | 发出命令后若一段时间没有回复，触发告警或重发 |
| 延时动作 | 复位设备后等待若干秒再发送下一条 |

## 注意

"延长计时"与"超时后再发一条"同时开启时，兜底可能被连续到达的消息不断推后，配置前先确认设备实际发送频率。
