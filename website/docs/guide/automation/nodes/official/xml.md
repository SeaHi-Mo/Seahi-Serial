# xml

## 作用

在 XML 文本与对象之间转换，用于与以 XML 报文交互的设备或服务通信。

## 属性设置

| 参数 | 设置方法 |
|---|---|
| 转换方向 | XML 转对象，或对象转 XML |
| 属性处理 | 元素属性如何表示（例如放在 `$` 字段下） |
| 根节点 | 生成 XML 时的根元素名称 |
| 输出属性 | 覆盖原字段或写入其他字段 |

## 常见用途

| 场景 | 做法 |
|---|---|
| 解析设备报文 | 把 XML 回复转成对象后用 `switch` 取字段 |
| 构造下发报文 | 先拼对象，再转成 XML 文本发送 |

## 注意

不同 XML 结构在转换为对象时可能产生数组或单值两种形态，取值前建议先用 `debug` 确认实际结构。
