# serial rxd

## 作用

轮询端口并把收到的数据转换成消息。格式选文本时 `payload` 是字符串，便于与应答关键字比较；选 HEX 或 Buffer 时按字节输出，同时保留 `msg.raw`。

## 属性设置

双击画布上的节点打开属性面板。

| 参数 | 设置方法 |
|---|---|
| 名称 | 画布上显示的文字，只影响可读性；留空显示 `serial rxd` |
| 端口 | 下拉选择当前已打开的串口 |
| 格式 | `文本` / `HEX` / `Buffer`；文本模式适合直接匹配 `OK`、`ERROR` 等关键字 |
| 轮询 ms | 读取队列的间隔，默认 100 毫秒，最小 20；越小延迟越低，读取越频繁 |

文本模式下消息可能被切分到多条，按行处理的场景需要在下游自行拼接。

## 常见用途

| 场景 | 做法 |
|---|---|
| 抓取设备启动日志 | 直接接 `debug`，观察上电后的完整输出 |
| 收到关键字后执行动作 | 接 `switch` 按内容分支，命中后接 `serial txd` 回复 |
| 记录设备输出 | 接 `debug` 或写入文件节点，长期观察运行状态 |

## 注意

同一端口只放置一个 `serial rxd`。节点的接收队列取走即清，两个节点会互相分走数据块；需要在多处使用数据时，从它的输出向下游分叉。

端口由程序独占，节点不自行打开串口。串口面板没有打开端口时，节点状态会提示没有可用端口。
