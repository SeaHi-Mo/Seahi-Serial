# serial txd

## 作用

把收到的消息写入已打开的串口。文本模式按 UTF-8 编码发送，并可追加行尾；HEX 模式把十六进制串解析为字节，按原样写出。

## 属性设置

双击画布上的节点打开属性面板。

| 参数 | 设置方法 |
|---|---|
| 名称 | 画布上显示的文字，只影响可读性；留空显示 `serial txd` |
| 端口 | 下拉选择当前已打开的串口，显示为 `COM3 · 115200`；新节点默认选中第一个可用端口 |
| 格式 | `文本` 把 `msg.payload` 按字符串发送；`HEX` 把十六进制串解析成字节发送 |
| 行尾 | 仅文本模式生效，可选 `CRLF` / `CR` / `LF` / 不加 |

端口下拉只列出已打开的串口。端口关闭后节点状态显示 `COM17 没有打开`，一个可用端口都没有时显示 `没有可用的串口`。

HEX 模式下 `payload` 必须是偶数长度的十六进制串，否则节点报错并且不发送，避免把无效字节写进设备。

## 常见用途

| 场景 | 做法 |
|---|---|
| 定时发送心跳 | `inject` 按间隔触发，节点只负责写入串口 |
| 手动测试一条指令 | `inject` 手动触发一次，在串口面板观察收发 |
| 发送上游算好的内容 | 接在 `function`、`change` 或 `switch` 之后，`payload` 即要发送的内容 |

发送结果会出现在串口监视窗口，与手动发送走同一条路径；关闭「消息回显」后不再显示。
