# 蓝牙调试

打开蓝牙面板，点「开始扫描」搜索周围的 BLE 设备。列表会显示设备名称、MAC 地址和 RSSI。

## 扫描与连接

点设备卡片进行连接。连接成功后，右侧会展开 GATT 服务树。

连接设备时如果仍在扫描，程序会自动停止扫描。连接期间再次扫描是允许的，用于查找下一台设备；新的连接同样会停止扫描。

每次扫描都有固定时长，到时间自动停止。

## 按 MAC 直接连接

被 Windows 配对过，或者被其他主机连接过的设备，往往不再广播，因此不会出现在扫描列表里。这类设备可以使用「按 MAC 直连」：直接输入地址连接，不依赖广播。

## GATT 服务树

服务和特征名称来自 Bluetooth SIG 的 UUID 表，内置 78 个服务和 512 个特征。表中没有的 UUID 会显示为 `Custom Service`，程序不会猜测名称。

在服务树里可以读取特征、写入特征和描述符、订阅通知与指示。原始字节按 HEX 显示，文本类特征会同时给出可读内容。

## 时间服务

程序能识别 Current Time Service：

| 特征 | 内容 |
|---|---|
| `0x2A2B` | 当前时间 |
| `0x2A0F` | 时区与夏令时 |
| `0x2A14` | 时间源、精度、距上次对时 |

读到或收到这些数据时，数据日志会在原始 HEX 后面补充一行可读时间，例如：

```
→ 2026-12-17T15:45:58.500Z（周四） · 设备时钟比本机快 …
```

订阅之后可以观察设备时钟的变化。

设备没有提供字段、数值超出范围或使用保留值时，界面显示「未给出」。`0` 也是一个有效取值，不会用来代替「不知道」。

## 设备名称

Windows 在连接成功后，会用系统缓存的名字覆盖设备名称。这个名字可能和设备实际广播的名称不同，甚至可能是设备从未使用过的名称。

界面展示的名称以广播名为准，系统名只在设备完全没有广播名称时作为兜底。

要确认设备自称的名称，可以读取 `0x1800` 服务下的 `0x2A00`（Device Name）。

## 配对

需要绑定的设备通过 WinRT 配对。配对过程中 Windows 会弹出系统确认框，需要手动确认；程序无法代替操作，这段时间请不要关闭窗口。

## 从机模式

BLE 从机（外设）功能已移除。适配器虽然报告支持外设角色，但实测广播无法启动，因此下线该功能，避免留下无法使用的入口。目前仅保留主机方向。
