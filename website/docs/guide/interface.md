## 标题栏

| 入口 | 行为 |
|---|---|
| 应用图标 | 回到串口主界面（从 WSL / ADB / 蓝牙页返回）；悬停显示版本号与 commit |
| ＋ | 新增分栏：串口页增加一个额外监视器（复制主分栏配置并自动加宽窗口）；WSL 页增加 WSL 监视器；蓝牙页开关右侧的内嵌串口监视器；ADB 页不可用 |
| WSL | 打开 WSL 端口映射页，进入后再点这个按钮返回串口主界面 |
| ADB | 打开 ADB 调试页，再点返回 |
| 蓝牙 | 打开蓝牙调试页，再点返回 |
| MCP | 打开 MCP 服务器弹窗，图标右下角的状态点表示服务器状态 |
| 主题风格 | 6 种配色风格下拉，见[主题](/guide/theme) |
| 提交 issue | 用系统浏览器打开 [GitHub 新建 issue](https://github.com/SeaHi-Mo/Seahi-Serial/issues/new) |
| 更新 | 只有检查到新版本时才出现 |
| 深浅色开关 | 在深色与浅色之间切换 |
| 最小化 / 最大化 / 关闭 | 窗口控制；最大化按钮再点一次还原 |

页面切换是整页替换：WSL / ADB / 蓝牙各自是一个整页，顶栏对应按钮会高亮，再点一次回到串口主界面。应用图标也做同一件事。

### 更新按钮

更新按钮默认隐藏。启动约 2 秒后检查一次更新，之后每 10 分钟检查一次；发现新版本时按钮出现，文字是「更新」加最新版本号。

点击后按钮先变成「正在下载...」，下载完变成「正在安装...」，然后启动安装程序并退出当前程序（退出前会保存配置）。下载时会用 GitHub 给出的 SHA-256 或文件大小做校验，校验失败会中止安装。安装或下载失败会弹出「更新失败: …」并把按钮恢复可点；日常检查失败不弹窗，只记日志并走错误上报。

### 窗口控制与拖动

- 顶栏最右侧是最小化、最大化/还原、关闭三个按钮。
- 在顶栏空白处按住可以拖动窗口；按在按钮、下拉框、输入框等交互控件上不会触发拖动。
- 关闭窗口时会先保存配置和窗口位置/尺寸，再释放串口、停止后台线程并退出。

## 首次使用引导

第一次启动时（本机还没有引导完成标记），界面就绪约 600ms 后会出现 9 步引导：

1. 全局操作栏：左侧新增分栏与 WSL，右侧主题、反馈与深浅色。
2. 选择串口：下拉选择端口，插拔设备后列表自动刷新。
3. 设置波特率：输入或选择波特率，默认 115200。
4. 启动监控：确认端口和波特率后连接串口。
5. 工具栏按钮：清空、自动滚动、自动重连、终端模式、行号、时间戳、消息回显和更多设置。
6. 发送数据：Text / HEX 两种发送模式与发送历史。
7. 快速指令：输出区右侧默认折叠的那条分栏。
8. 高级设置：齿轮里的数据位、停止位、校验位、DTR/RTS 控制和日志保存。
9. 开始使用：结束引导。

- 「下一步」推进；最后一步的按钮变成「开始使用」。
- 「跳过」或点引导层空白处会立即关闭。
- 完成或跳过后会记下标记，之后启动不再自动出现。

## MCP 服务器弹窗

点标题栏的 MCP 图标打开。图标右下角的小圆点表示服务器状态：

- 灰色：未启用，或状态还没读到。
- 绿色：已启用，当前没有客户端会话。
- 强调色（通常蓝色）：已启用，且有客户端连着。
- 红色：未启用，且上次出错（弹窗里的「上次错误」会写明）。

弹窗里可以启用/关闭服务器、切换只读模式、选择传输形态（HTTP / SSE / All）、复制两种连接地址与对应的客户端配置、复制安装提示词、重置访问令牌，并查看状态和上次错误。连接与配置步骤见 [MCP 接入](/guide/mcp)。

## 主题风格与深浅色

主题风格下拉提供 6 种：默认、浮世绘彩、诗意东方、水墨丹青、桃之夭夭、金风玉露。每种都有浅色和深色两套，共 12 套主题。

- 下拉里的选项切换配色风格；右侧的深浅色开关在浅色与深色之间切换。
- 切换会同时更新输出区、终端、侧边栏和按钮，顶栏底色也跟着变。
- 选择写入 config.json，下次启动沿用；首次启动（还没有保存选择）跟随系统深浅色。
- 运行中系统切换深浅色时，程序也会跟着切。

完整说明见[主题](/guide/theme)。

## 启动兜底页

界面初始化时会先显示「正在初始化界面…」，主面板创建成功后自动隐藏。以下情况会换成兜底页：

- 初始化失败、主面板没有建起来：标题变成「界面初始化失败」，下面显示错误详情。
- 8 秒内主面板仍未创建：标题变成「界面初始化超时」，并提示重新加载。

兜底页有两个按钮：「重新加载」刷新页面，「退出应用」关闭程序。走到这一步的错误也会进入错误上报。

主窗口启动时是隐藏的（避免先闪一下默认尺寸），页面就绪后再显示；任何兜底路径都会先显示窗口，后端还会在 4 秒后强制显示一次，避免出现「程序启动了却看不到窗口」。

## 窗口位置与尺寸记忆

窗口的位置、大小和最大化状态记在 `window.json`，下次启动时恢复：

- 拖动或缩放窗口时约 400ms 去抖保存；关闭窗口时强制保存。
- 最大化时保留最近一次普通尺寸，取消最大化后回到那个尺寸。
- 启动时窗口先隐藏，恢复几何后一次性显示，所以不会先出现默认尺寸再跳变。
- 恢复的位置如果不在任何显示器的可见范围内（比如拔掉了副屏），位置会被忽略，窗口保持默认居中。
- 窗口最小尺寸是 838×650。
- 从没有 `window.json` 的更老版本升级时，会用 `config.json` 里的旧尺寸字段兜一次。

## 配置与数据目录

数据目录是 `%APPDATA%\seahi-serial`。在 `Win + R` 里输入 `%APPDATA%` 再进入 `seahi-serial` 即可。

| 文件 | 作用 |
|---|---|
| config.json | 界面与设备设置：主题、各监视器、快速指令、工作流、日志目录、WSL 自动映射、蓝牙页状态、OTA 协议档等。改动后约 500ms 去抖写入，关闭或退出时强制保存；配置版本无法识别时会先备份为 config.json.bak |
| window.json | 窗口位置、尺寸、最大化状态；由后端在移动/缩放（约 400ms 去抖）和关闭时写入 |
| ai-config.json | MCP 服务器设置：开关、主机、端口、访问令牌、只读模式、传输形态、调用记录设置；原子写入，与 config.json 严格隔离 |
| ai-calls.jsonl | AI 工具调用记录，每次调用一行 JSON，追加写入并按份轮转；记录开关在 MCP 设置里 |
| log-cache | 会话日志的隐形缓存（`session-*.log`），会话有收发内容时自动写，不需要手动保存；最多 10 个文件、单文件 8 MiB、总量约 64 MiB |

## 常见快捷键

| 位置 | 按键 | 行为 |
|---|---|---|
| 发送输入框 | Enter | 发送当前内容；历史下拉打开且有选中项时先填入那一项（这一次不发送） |
| 发送输入框 | ↑ | 填入上一条发送历史；历史下拉打开时改为向上选择 |
| 发送输入框 | ↓ | 打开发送历史下拉；已打开时向下移动选择 |
| 发送输入框 | Esc | 关闭历史下拉并重置历史位置 |
| 终端（行缓冲） | ↑ / ↓ | 翻本地命令历史 |
| 终端（行缓冲） | ← / →、Home / End、Delete、Backspace | 在本地编辑当前行，不发给设备 |
| 终端（行缓冲） | Ctrl+C | 冲掉半行并发送中断 0x03 |
| 终端（行缓冲） | Ctrl+U | 清空当前行 |
| 终端（行缓冲） | Enter / Tab | Enter 发送整行并追加行尾；Tab 发送 0x09 |
| 终端（任意模式） | Ctrl+Shift+C | 复制终端里选中的文字 |
| 终端（直发） | 任意键 | 原样发送，包括方向键和 Ctrl 组合键 |

工具栏里的「命令行缓冲」开关控制这两种模式；完整说明见[终端模式](/guide/terminal)。

## 错误上报

程序没有单独的上报按钮：前端未捕获的脚本错误、未处理的 Promise 拒绝和界面上已经提示过的错误由统一入口上报，后端运行期错误也会上报。同类错误 5 分钟内只报一次；上报失败只在本地日志留一行，不影响使用。关闭上报用环境变量 `SEAHI_ERROR_REPORT=0`，本地调试日志在 `%TEMP%\seahi-serial-debug.log`。

上报字段、时机、数据去向与关闭方式见[错误上报](/guide/error-reporting)。
