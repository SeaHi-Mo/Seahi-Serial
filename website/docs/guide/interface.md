# 界面与设置

程序使用无边框窗口，顶部为自绘标题栏，包含窗口控制、页面入口、主题与反馈入口。以下按标题栏从左到右说明，并依次介绍首次使用引导、MCP 服务器弹窗、主题、启动兜底页、窗口位置与尺寸记忆、配置与数据目录、常见快捷键和错误上报。

## 标题栏

| 入口 | 行为 |
|---|---|
| 应用图标 | 返回串口主界面（从 WSL / ADB / 蓝牙页面返回）；悬停显示版本号与 commit |
| ＋ | 新增分栏：在串口页面新增一个额外监视器（复制主分栏配置并自动加宽窗口）；在 WSL 页面新增 WSL 监视器；在蓝牙页面切换右侧内嵌串口监视器；ADB 页面不可用 |
| WSL | 打开 WSL 端口映射页面；再次点击该按钮返回串口主界面 |
| ADB | 打开 ADB 调试页面；再次点击返回 |
| 蓝牙 | 打开蓝牙调试页面；再次点击返回 |
| MCP | 打开 MCP 服务器弹窗；图标右下角的状态点表示服务器状态 |
| 主题风格 | 6 种配色风格下拉列表，见[主题](/guide/theme) |
| 提交 issue | 使用系统浏览器打开 [GitHub 新建 issue](https://github.com/SeaHi-Mo/Seahi-Serial/issues/new) |
| 更新 | 仅在检测到新版本时显示 |
| 深浅色开关 | 在深色与浅色之间切换 |
| 最小化 / 最大化 / 关闭 | 窗口控制；最大化按钮再次点击可还原 |

页面切换采用整页替换方式：WSL、ADB 与蓝牙分别为独立页面，顶栏对应按钮会高亮，再次点击返回串口主界面。应用图标执行相同操作。

### 更新按钮

更新按钮默认隐藏。程序在启动约 2 秒后检查更新，之后每 10 分钟检查一次；检测到新版本时按钮显示，文本为「更新」加最新版本号。

点击后按钮依次显示「正在下载...」和「正在安装...」，随后启动安装程序并退出当前程序，退出前保存配置。下载使用 GitHub 提供的 SHA-256 或文件大小进行校验，校验失败会中止安装。下载或安装失败时显示「更新失败: …」并恢复按钮可用状态；常规检查失败不显示弹窗，仅写入日志并上报错误。

### 窗口控制与拖动

顶栏最右侧为最小化、最大化/还原和关闭按钮。在顶栏空白区域按住可拖动窗口；在按钮、下拉框和输入框等交互控件上按下不会触发拖动。关闭窗口时先保存配置与窗口位置/尺寸，再释放串口、停止后台线程并退出。

## 首次使用引导

首次启动时（本机尚无引导完成标记），界面就绪约 600ms 后显示 9 步引导：

1. 全局操作栏：左侧为新增分栏与 WSL 入口，右侧为主题、反馈与深浅色入口。
2. 选择串口：从下拉列表选择端口，设备插拔后列表自动刷新。
3. 设置波特率：输入或选择波特率，默认 115200。
4. 启动监控：确认端口和波特率后连接串口。
5. 工具栏按钮：清空、自动滚动、自动重连、终端模式、行号、时间戳、消息回显和更多设置。
6. 发送数据：Text / HEX 两种发送模式与发送历史。
7. 快速指令：输出区右侧默认折叠的分栏。
8. 高级设置：齿轮菜单中的数据位、停止位、校验位、DTR/RTS 控制和日志保存。
9. 开始使用：结束引导。

点击「下一步」进入下一步；最后一步的按钮文本为「开始使用」。点击「跳过」或引导层空白区域会立即关闭引导。完成或跳过会写入完成标记，后续启动不再自动显示。

## MCP 服务器弹窗

点击标题栏的 MCP 图标打开弹窗。图标右下角的状态点表示服务器状态：

| 状态点 | 含义 |
|---|---|
| 灰色 | 未启用，或状态尚未读取 |
| 绿色 | 已启用，当前无客户端会话 |
| 主题强调色 | 已启用，且存在客户端连接 |
| 红色 | 未启用，且上次运行出现错误 |

弹窗中可执行以下操作：启用或关闭服务器、切换只读模式、选择传输形态（HTTP / SSE / All）、复制两种连接地址及对应客户端配置、复制安装提示词、重置访问令牌，并查看状态与上次错误。错误原因显示在弹窗的「上次错误」中。连接与配置步骤见 [MCP 接入](/guide/mcp)。

## 主题风格与深浅色

主题风格下拉列表提供 6 种风格：默认、浮世绘彩、诗意东方、水墨丹青、桃之夭夭、金风玉露。每种风格包含浅色和深色两套，共 12 套主题。

下拉选项用于切换配色风格，右侧深浅色开关用于在浅色与深色之间切换。切换会同时更新输出区、终端、侧边栏和按钮，标题栏背景色同步变化。选择写入 config.json，下次启动时沿用；首次启动且尚无保存选择时，使用系统深浅色设置。运行期间系统设置变化不会自动切换，避免覆盖已保存的选择。

完整说明见[主题](/guide/theme)。

## 启动兜底页

界面初始化期间首先显示「正在初始化界面…」，主面板创建成功后自动隐藏。以下情况会显示兜底页：

- 初始化失败且主面板未创建：标题显示「界面初始化失败」，下方显示错误详情。
- 主面板在 8 秒内仍未创建：标题显示「界面初始化超时」，并提示重新加载。

兜底页提供「重新加载」（刷新页面）和「退出应用」（关闭程序）两个按钮。进入兜底页的错误同时上报错误收集服务。

主窗口启动时隐藏，以避免先显示默认尺寸再跳变；页面就绪后显示。所有兜底路径都会先显示窗口，后端在 4 秒后再次强制显示，避免程序启动后没有可见窗口。

## 窗口位置与尺寸记忆

窗口的位置、大小和最大化状态记录在 `window.json`，下次启动时恢复。拖动或缩放窗口时约 400ms 去抖保存，关闭窗口时强制保存。

最大化时保留最近一次普通尺寸，取消最大化后恢复该尺寸。启动时窗口先隐藏，恢复几何后一次性显示，因此不会先出现默认尺寸再跳变。

恢复的位置如果不在任何显示器的可见范围内（例如副屏已拔出），位置会被忽略，窗口保持默认居中。窗口最小尺寸为 838×650。从没有 `window.json` 的旧版本升级时，使用 `config.json` 中的旧尺寸字段作为一次性回退。

## 配置与数据目录

数据目录为 `%APPDATA%\seahi-serial`。在 `Win + R` 中输入 `%APPDATA%`，然后进入 `seahi-serial` 目录。

| 文件 | 作用 |
|---|---|
| config.json | 界面与设备设置：主题、各监视器、快速指令、工作流、日志目录、WSL 自动映射、蓝牙页状态、OTA 协议档等。修改后约 500ms 去抖写入，关闭或退出时强制保存；配置版本无法识别时备份为 config.json.bak |
| window.json | 窗口位置、尺寸和最大化状态；由后端在移动/缩放（约 400ms 去抖）和关闭时写入 |
| ai-config.json | MCP 服务器设置：开关、主机、端口、访问令牌、只读模式、传输形态、调用记录设置；原子写入，与 config.json 严格隔离 |
| ai-calls.jsonl | AI 工具调用记录，每次调用一行 JSON，追加写入并按份轮转；记录开关位于 MCP 设置中 |
| log-cache | 会话日志的隐形缓存（`session-*.log`），会话有收发内容时自动写入，无需手动保存；最多 10 个文件、单文件 8 MiB、总量约 64 MiB |

## 常见快捷键

| 位置 | 按键 | 行为 |
|---|---|---|
| 发送输入框 | Enter | 发送当前内容；历史下拉列表打开且存在选中项时先填入该项，本次不发送 |
| 发送输入框 | ↑ | 填入上一条发送历史；历史下拉列表打开时改为向上选择 |
| 发送输入框 | ↓ | 打开发送历史下拉列表；列表已打开时向下移动选择 |
| 发送输入框 | Esc | 关闭历史下拉列表并重置历史位置 |
| 终端（行缓冲） | ↑ / ↓ | 浏览本地命令历史 |
| 终端（行缓冲） | ← / →、Home / End、Delete、Backspace | 在本地编辑当前行，不发送至设备 |
| 终端（行缓冲） | Ctrl+C | 清除当前半行并发送中断 0x03 |
| 终端（行缓冲） | Ctrl+U | 清空当前行 |
| 终端（行缓冲） | Enter / Tab | Enter 发送整行并追加行尾；Tab 发送 0x09 |
| 终端（任意模式） | Ctrl+Shift+C | 复制终端中选中的文字 |
| 终端（直发） | 任意键 | 原样发送，包括方向键和 Ctrl 组合键 |

工具栏中的「命令行缓冲」开关用于选择这两种输入模式；完整说明见[终端模式](/guide/terminal)。

## 错误上报

程序不提供单独的上报按钮。前端未捕获的脚本错误、未处理的 Promise 拒绝和界面已提示的错误由统一入口上报，后端运行期错误同样上报。同类错误在 5 分钟内仅上报一次；上报失败时仅在本地日志写入一行，不影响使用。关闭上报需设置环境变量 `SEAHI_ERROR_REPORT=0`，本地调试日志位于 `%TEMP%\seahi-serial-debug.log`。

上报字段、上报时机、数据去向与关闭方式见[错误上报](/guide/error-reporting)。
