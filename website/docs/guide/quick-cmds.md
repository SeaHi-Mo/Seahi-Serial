# 快速指令

监控区最右侧那条窄条就是快速指令面板（默认折叠，点一下展开，拖动可调宽）。它要解决的是「自动化一串有来有回的指令」，比如配网、校准、批量烧参数。

## 一组一张表

指令按**循环组**分段：**抬头 → 列标题 → 数据行**。

| 抬头上的东西 | 作用 |
|---|---|
| 参与开关 | 关掉 = **整组跳过**（顺序号原样保留，点回来即恢复） |
| 拖动握把 | 拖到最上面的那组就是**循环起点** |
| 组名 | 点一下改名（也等于改文件里那行 `## 抬头`） |
| 折叠箭头 | 收起整组，只留抬头 |
| 条数 / 删组 | 这一组有几条 / 删掉整组（**最后一组删不掉**） |

每组表头最右还有 **＋ 添加**。首次启动默认 1 组；新建组默认带 1 条空指令。

## 每条指令的一行

| 格子 | 说明 |
|---|---|
| 顺序号 | `0` = 不参与循环；大于 `0` 的按**组内从小到大**依次发送 |
| 指令内容 | 文本模式下回车即发；`\r\n` 这类转义生效 |
| 超时(ms) | **这一条占用的时间**，默认 `3000`（含义见下） |
| HEX | 本条按十六进制发送（与主发送栏的模式无关，可一条文本一条 HEX 混跑） |
| 发送 / 删除 | 单独发这一条 / 删掉 |

::: tip 「超时」是节奏，不只是等待上限
- 写了「期望」：它是**等回话的上限**。
- 没写「期望」：它就是**发下一条前的间隔**（`3000` = 每 3 秒一条）。
- 填 `0`：按 20ms 最小间隔连发（防死循环）。
:::

## 循环发送：发一条，等它回话

标题行左侧的 **循环发送** 开关，点一下开始、再点一下停。

| 收到的回话 | 下一步 |
|---|---|
| `busy` | 继续等（不算结论） |
| `OK` | 走**成功跳转**（默认下一条） |
| `ERROR` | **重发本条**（默认 3 次，可在文件里改）；用尽后走**失败跳转** |
| 等满「超时」 | 也算失败，走**失败跳转** |

⚠️ **只有「超时 > 0」且「期望」非空的条目才会等回话**。没写成功词就无从判定——它有节奏地发，但不校验回话。

- 顺序：组从上到下 → 组内顺序号从小到大，一轮发完回到最上面那组。
- 跳转：文件里可写 `成功跳转` / `失败跳转`。留空 = 下一条；数字 = 跳到该顺序号；`结束` = 收尾停下。目标不存在时**降级按「下一条」**并说明原因，连续跳转超过 200 次会自愈停止。
- **循环里不写日志**：跑起来之后输出区一个字都不会多（设备自己的数据除外）。面板上亮着的开关、折叠条上的小点就是它还在跑的信号。
- 掉线、关掉分栏、或链上再没有可发的条目，会**自愈停止**并弹一次提示。
- 开关状态**不持久化**——开机自动发指令太危险。

## 挂到外部文件上

标题行的「导入」可以把指令列表挂到一个 Markdown 文件上，之后增删改都**写回那个文件**：

- `#` 注释、表头、额外列**原样保留**；用 `## 组名` 抬头分隔循环组（单个 `#` 仍是注释）。
- 表头写了哪几列就管哪几列：`名称 | 指令 | 顺序号 | 超时(ms) | 期望 | 重试 | 成功跳转 | 失败跳转 | HEX`。
- 没写这些列的老文件**按老规矩**读：第 3 列起是你的备注，原样保留，不会被当成顺序号改写。
- 写回是**原子**的（临时文件 + rename）；写之前比对内容哈希，文件被别的编辑器改过会**报冲突**而不是静默覆盖。
- 「导出」得到的是一份**自包含副本**（一律补全这几列），换台机器导入，循环配置一项不丢。

文件格式的完整说明（列名与别名、文件头、写回规则、上限、FAQ）见
[QUICK_CMDS.md](https://github.com/SeaHi-Mo/Seahi-Serial/blob/main/doc/QUICK_CMDS.md)。
