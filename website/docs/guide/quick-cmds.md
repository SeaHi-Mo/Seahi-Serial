# 快速指令

快速指令面板在输出区右侧，默认折叠。点一下展开，拖动可以调整宽度。它用来执行一组需要来回交互的指令，例如配网、校准或批量写入参数。

## 分组

指令按循环组管理，每组包含组名、列标题和数据行。

- 组名可以点击修改，对应文件里的 `## 组名`。
- 拖动组标题可以调整顺序，排在最上面的组是循环起点。
- 折叠箭头收起整组，只保留标题。
- 关掉组标题上的开关会跳过整组，顺序号不会改变，重新打开即可恢复。
- 每组右上角有「＋ 添加」。首次启动默认一组，新建组会自带一条空指令。

## 一条指令的字段

| 字段 | 说明 |
|---|---|
| 顺序号 | `0` 表示不参与循环，大于 `0` 的按组内顺序从小到大发送 |
| 指令内容 | 文本内容，回车发送；`\r\n` 这类转义会生效 |
| 超时(ms) | 这条指令的等待时间或发送间隔，默认 3000 |
| HEX | 本条按十六进制发送，和主发送栏的模式无关 |
| 发送 / 删除 | 单独发送这一条，或删除 |

## 超时的含义

超时不只是等待上限，也决定发送节奏。

- 填写了「期望」时，超时是等待设备回话的最长时间。
- 没有填写「期望」时，超时是发下一条之前的间隔。填 3000 就表示每 3 秒发一条。
- 填 0 时按 20ms 的最小间隔连续发送。

## 循环发送

标题行左侧的「循环发送」开关控制启停。

| 收到的回话 | 下一步 |
|---|---|
| `busy` | 继续等待 |
| `OK` | 走成功跳转，默认下一条 |
| `ERROR` | 重发本条，默认 3 次，次数可在文件里修改；用尽后走失败跳转 |
| 等待超时 | 视为失败，走失败跳转 |

只有同时设置了「超时大于 0」和「期望非空」的条目才会等待回话。没有成功判定词时，程序只按节奏发送，不检查设备返回内容。

循环顺序是组从上到下、组内顺序号从小到大，一轮结束后回到最上面的组。

跳转在文件里配置。成功跳转和失败跳转留空表示下一条，数字表示跳到对应顺序号，`结束` 表示停止。目标不存在时按「下一条」处理并给出说明；连续跳转超过 200 次会自动停止。

循环运行期间不会往日志窗口写内容，输出区里只有设备自己的数据。面板上的开关和折叠条上的小点表示循环仍在运行。

掉线、关闭分栏或没有可发送的条目时，循环会自动停止并提示一次。开关状态不会保存，避免程序启动后自动向设备发送指令。

## 挂到外部文件

标题行的「导入」可以把指令列表关联到一个 Markdown 文件，之后的增删改都会写回该文件。

- `#` 注释、表头和额外列原样保留。`## 组名` 用来分隔循环组，单个 `#` 仍是注释。
- 表头写了哪些列就处理哪些列：`名称 | 指令 | 顺序号 | 超时(ms) | 期望 | 重试 | 成功跳转 | 失败跳转 | HEX`。
- 没有这些列的老文件按原有规则读取，第 3 列起视为备注，不会被改写成顺序号。
- 写回采用临时文件加 rename 的方式，写回前会比对内容哈希。文件被其他编辑器修改过时返回冲突，不会覆盖。
- 「导出」生成一份自包含副本，列会自动补全，换一台机器导入后循环配置不会丢失。

列名、文件头、写回规则和上限等完整说明见
[QUICK_CMDS.md](https://github.com/SeaHi-Mo/Seahi-Serial/blob/main/doc/QUICK_CMDS.md)。
