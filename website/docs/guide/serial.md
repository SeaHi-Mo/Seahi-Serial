# 串口调试

## 一个窗口，多路串口

顶栏 **＋ 打开额外监视器** 可以加一个分栏。每栏有**独立的端口、波特率、行尾与发送历史**，互不影响：

- 同时看两块板子的日志、分别发指令，不用来回切窗口。
- 分栏可以关闭；关掉的那一路的连接会一并释放。

## 工具栏上有什么

| 控件 | 作用 |
|---|---|
| 查看模式 | 输出按**文本**或**HEX** 显示 |
| 端口 | 选 COM 口；插拔设备自动刷新 |
| 波特率 | 常用档位 + 自定义输入 |
| 行尾 | 发送时追加 `\r` / `\n` / `\r\n` |
| 开始 / 停止监控 | 连接与断开 |
| 齿轮 | 展开高级设置：数据位、停止位、校验位、DTR / RTS |
| 清屏 / 保存日志 | 清空输出区 / 通过系统文件对话框导出 |

图标按钮里还有：显示行号、时间戳、消息回显、终端模式、命令行缓冲。

## 发送

- 文本模式按 UTF-8 发出；HEX 模式按字节发（`AA 55 01` 这样写）。
- 行尾按工具栏的选择追加；**AT 指令建议行缓冲 + `\r\n`**（见 [终端模式](/guide/terminal)）。
- 发送历史每栏独立保存最近 **50** 条，`↑` / `↓` 翻，`Esc` 关掉历史下拉。

## 日志与缓存

- **清屏**只影响显示，不影响已落盘的会话缓存。
- 每次打开串口、且有收发内容时，自动缓存到：

  ```
  %APPDATA%\seahi-serial\log-cache\session-<时间戳>-<端口>.log
  ```

  最多保留 **10** 个，新建时淘汰最旧的。
- 要长期保留，用 **保存日志** 自己选路径另存；程序不会自动删你手动存的文件。

## 断线之后

串口断开后会自动尝试重连（按钮显示「等待接入」，端口状态点变色）。重连过程**不写日志窗口**——输出区里的内容始终只有设备数据，不会混进程序自己的提示。

## 工作流：收到什么就做什么

「更多设置 → 工作流」可以配一条 **收到匹配数据 → 自动执行动作**（发数据 / 切 DTR·RTS / 存日志）的规则：

- 规则可单独启停；命中后写进独立的 `workflow` 日志通道，事后能查「刚才自动发了什么、什么时候发的」。
- ⚠️ 让规则跑起来是**危险动作**（会自动往设备发数据），界面上要点确认；AI 侧必须带 `confirm:true`。

## 主题

顶栏可选 **6 种风格 × 深浅色 = 12 套主题**。主题跟着终端模式和普通输出区一起换，不是只换外壳。
