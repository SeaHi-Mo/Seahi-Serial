# 串口调试

启动后默认显示串口页。一个分栏就是一个串口监视器，可以并排放多个，分别选端口、波特率和行尾。

## 分栏

顶部栏左侧的「＋」新增一个分栏。在 WSL 页面里它新增 WSL 分栏，在蓝牙页面里它开关右侧的内嵌串口监视器，行为跟着当前页面走。

- 新分栏沿用主分栏的波特率、行尾、显示开关和快速指令，端口可以在自己的工具栏里另选，发送历史从空开始。
- 分栏数量没有上限。新开分栏时窗口不够宽会自动加宽（每栏按 419px 估算），再窄就由分栏容器横向滚动。
- 额外分栏顶部右上角有「✕」。关闭时会释放它占用的串口（最多等 3 秒），同时收掉终端画布和循环发送定时器。主分栏没有关闭按钮。
- 每个分栏独立：一个分栏打开着的端口，在其它分栏的端口下拉里标为「占用中」，点不动。

顶部栏的应用图标回到串口页，WSL、ADB、蓝牙图标各打开对应页面。切到别的页面时串口不会断开，接收轮询从 25ms 降到 500ms，切回来立刻恢复。

## 工具栏

| 控件 | 作用 |
|---|---|
| 查看 | 输出按文本或 HEX 显示。只管显示，不改发送格式 |
| 端口 | 选择 COM 口；「刷新」按钮手动刷新，插拔设备时也会自动刷新 |
| 波特率 | 33 个常用档位（50–4000000），也可以直接输入（110–4000000），默认 115200 |
| 行尾 | CRLF、LF、CR 或「无」，默认 CRLF |
| 开始 / 停止监控 | 打开或关闭串口；停止会释放端口 |
| 图标按钮 | 清除内容、自动滚动、自动重连、终端模式、命令行缓冲、显示行号、时间戳、消息回显、更多设置 |
| 更多设置 | 展开数据位、停止位、校验位、DTR/RTS、日志目录、工作流等 |

波特率在连接中修改会自动重连：断开旧连接，按新波特率重新打开。

端口在监控中修改也一样：先释放旧端口，再连新端口，输出区里会写一行切换提示。端口被别的分栏占用时不会切换。

## 图标按钮

- 清除内容：清空输出区、终端画布和内存缓冲，同时截断当前会话的磁盘缓存文件。
- 自动滚动：默认开。开着时输出区一直贴底；点进输出区编辑会临时暂停，鼠标移开或失焦后恢复。
- 自动重连：默认关，行为见后面的「断线重连」。
- 终端模式：把输出区换成 xterm 画布，见[终端模式](/guide/terminal)。
- 命令行缓冲：只在终端模式下可用，串口分栏默认开。
- 显示行号：给输出行加行号，空行不编号。
- 时间戳：每行前面加 `[时:分:秒.毫秒]`。
- 消息回显：发送时先把内容作为一行 `send` 显示在输出区，HEX 模式显示为 `HEX: AA 55`。关掉后输出区只显示设备返回。
- 更多设置：展开或收起下面那排高级项，新建分栏默认展开。

## 更多设置

- 数据位：5、6、7、8，默认 8。
- 停止位：1、2，默认 1。
- 校验位：无、奇校验、偶校验，默认无。
- DTR 默认不勾，RTS 默认勾。只在已连接时生效，连续点击按 100ms 防抖，最后只发一次。
- 选择日志目录：打开系统的文件夹选择框。选定后，「保存日志」和工作流里的「保存日志」动作都写到这个目录。
- 保存日志：把当前输出保存成 `Serial Debug 年-月-日 时分秒.txt`。它不是另存为对话框，直接写在上面选定的目录里；没选过目录会提示「未设置日志目录」。
- 复制全部：把内存里的完整日志复制到剪贴板，输出区里已经滚掉的部分也在里面。
- 折叠工具栏：把工具栏收成一条细边，鼠标移上去临时展开；再点一次恢复常驻。
- ＋ 添加规则：新建一条工作流规则，见后面的「工作流」。

## 发送

输入框里按回车或点「发送」。没连接时发送按钮是灰的。

发送格式在输入框右侧的「文本 / HEX」里选，和工具栏的「查看」互不影响：可以文本显示、HEX 发送，也可以反过来。

文本模式：

- 按 UTF-8 编码发送。
- 支持 `\r`、`\n`、`\t`、`\\` 四种转义。
- 发送前按工具栏「行尾」追加行尾。转义和行尾是两件事，行尾总会再追加一次。

HEX 模式：

- 忽略空白和 `0x` 前缀，两位一组解析，例如 `AA 55 0x01`。
- 奇数个十六进制字符报「Hex长度必须为偶数」，非十六进制字符报「无效Hex: xx」。报错只写进输出区，不会发送。
- HEX 发送不追加行尾。

发送历史：

- 每个分栏保留最近 50 条，连续重复的不重复记。
- `↑` 把最新一条往回填进输入框；`↓` 打开历史列表并选中最新一条，再按 `↓` 继续往下移动；列表里按回车填入选中项，`Esc` 关闭。
- 历史随配置保存最近 20 条，重启后还在。

## 接收区

- 文本模式按 UTF-8 流式解码，多字节字符跨轮询分块时不会变成乱码。
- 只有真正收到换行才换行：`\r\n`、`\n` 和单独的 `\r` 都算换行，数据分块本身不会制造假换行。
- HEX 模式按字节显示，每行最多 192 个十六进制字符，第一行带 `HEX:` 前缀。
- 滚到顶部会按 1000 行一批加载更早的缓冲。输出区保留的行数有上限，完整历史在内存缓冲里（8 MiB 预算，超出裁到一半），「保存日志」和「复制全部」读的是这份缓冲。
- 前端读取不及时（面板长时间隐藏、设备发得太快）时，后端接收缓冲到 256 KiB 就丢最旧的数据，并在输出区提示「已丢弃 N 字节」。

## 日志与缓存

「清除内容」不只是清屏：输出区、终端画布、内存缓冲和当前会话的磁盘缓存文件一起清掉。会话还没写过内容时什么也不做，也不报错。

串口打开后只要有收发，程序就会把这次会话缓存到磁盘，一个会话一个文件，收发内容按 300ms 批量写入：

```
%APPDATA%\seahi-serial\log-cache\session-<年月日-时分秒毫秒>-<端口>.log
```

- 目录里最多保留 10 个文件，建新文件之前先删最旧的。
- 单个文件到 8 MiB 后停止写入，末尾留一行终止标记，界面上提示一次；正在写入的文件不会被删除。
- 目录总量到 64 MiB 后按最旧的开始删。
- 自动重连沿用同一个缓存文件，日志保持连续；会话结束时文件还是空的就删掉。

需要长期保留时用「更多设置 → 保存日志」另存，程序不会自动删除手动保存的文件。

## 断线重连

自动重连按钮默认关。打开后，读数据时报错会走这条路径：

1. 关闭端口，按钮变成「等待接入」，端口下拉和发送按钮一起禁用。
2. 最多重连 10 次，间隔是 2 秒 × 第几次，最长 20 秒。
3. 连上就恢复「停止监控」；10 次都失败就回到「开始监控」，并结束这次会话缓存。

手动点「停止监控」不会触发自动重连。自动重连放弃后再点「开始监控」就是手动重连。

重连过程一行日志都不写，输出区里始终只有设备数据；进度只看按钮文字和端口状态点。

## 工作流

工作流规则在「更多设置」里，点「＋ 添加规则」新建，规则列表显示在工具栏下方。

一条规则包含：

- 名称、启用开关、运行 / 停止按钮、折叠和删除。
- 匹配条件：字符串包含、正则表达式、精确字节(HEX)。一条规则可以加多条条件，全部满足才算命中；跨轮询分块的数据也能匹配。
- 执行动作：发送数据（文本或 HEX，文本会追加当前行尾）、切换信号（DTR 或 RTS，高或低电平）、保存日志（把收到的数据追加到所选日志目录的 `workflow_log.txt`）。动作按顺序执行，每个动作可以设延时，单位毫秒。

规则只在监控期间检查。命中时输出区写一行 `[Auto] ...`，同一行也写进日志中心的 `workflow` 通道。

规则上限：每个分栏 50 条，每条最多 8 个条件、8 个动作；名称 64 字，条件值 512 字，动作数据 4096 字。

面板上点「运行」即可启动规则。MCP 侧规则一律以停止状态创建，启动要走 `serial_workflow_run` 并带 `confirm:true`。
