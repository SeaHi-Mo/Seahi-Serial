# 串口调试

串口页为程序启动后的默认页面。每个分栏对应一个串口监视器，多个分栏可以并行运行，各自选择端口、波特率与行尾。

## 分栏

工具栏左端的「＋」按钮用于新增分栏，按钮行为随当前页面变化：在 WSL 页面新增 WSL 分栏，在蓝牙页面开关右侧内嵌的串口监视器。

新增分栏会沿用主分栏的波特率、行尾、显示开关与快速指令，端口可在该分栏的工具栏中另行选择，发送历史从空开始。分栏数量没有上限；新增分栏时窗口宽度不足会自动加宽，估算标准为每栏 419 像素，仍不足时分栏容器横向滚动。

额外分栏顶部右侧提供「✕」按钮。关闭分栏时，程序释放该分栏占用的串口，最多等待 3 秒，同时销毁终端画布与循环发送定时器。主分栏没有关闭按钮。

端口由各分栏独立占用：某个端口被一个分栏打开后，其它分栏的端口下拉列表将该端口标记为「占用中」，不可选择。标题栏的应用图标返回串口页，WSL、ADB 与蓝牙图标分别打开对应页面；切换页面时串口连接保持，接收轮询间隔由 25ms 调整为 500ms，返回串口页后恢复。

## 工具栏

| 控件 | 作用 |
|---|---|
| 查看 | 输出按文本或 HEX 显示，仅影响显示，不改变发送格式 |
| 端口 | 选择 COM 口；「刷新」按钮手动刷新，插拔设备时自动刷新 |
| 波特率 | 33 个常用档位（50–4000000），也可直接输入（110–4000000），默认 115200 |
| 行尾 | CRLF、LF、CR 或「无」，默认 CRLF |
| 开始 / 停止监控 | 打开或关闭串口，停止时释放端口 |
| 图标按钮 | 清除内容、自动滚动、自动重连、终端模式、命令行缓冲、显示行号、时间戳、消息回显、更多设置 |
| 更多设置 | 展开数据位、停止位、校验位、DTR/RTS、日志目录与工作流等设置 |

波特率在连接期间修改会触发自动重连：程序关闭旧连接，按新波特率重新打开。端口在监控期间修改时，程序先释放旧端口，再连接新端口，并在输出区写入一行切换提示；目标端口被其它分栏占用时不会切换。

## 图标按钮

工具栏右侧为一组图标按钮，各按钮的默认状态与作用如下：

- 清除内容：清空输出区、终端画布与内存缓冲，并截断当前会话的磁盘缓存文件。
- 自动滚动：默认开启；开启时输出区保持贴底，点击输出区进入编辑会临时暂停，鼠标移开或失焦后恢复。
- 自动重连：默认关闭，行为见「断线重连」。
- 终端模式：将输出区替换为 xterm 画布，详见[终端模式](/guide/terminal)。
- 命令行缓冲：仅在终端模式下可用，串口分栏默认开启。
- 显示行号：为输出行添加行号，空行不编号。
- 时间戳：在每行前添加 `[时:分:秒.毫秒]`。
- 消息回显：发送时先将内容作为 `send` 行写入输出区，HEX 模式显示为 `HEX: AA 55`；关闭后输出区仅显示设备返回内容。
- 更多设置：展开或收起高级设置行，新建分栏默认展开。

## 更多设置

| 设置项 | 说明 |
|---|---|
| 数据位 | 5、6、7、8，默认 8 |
| 停止位 | 1、2，默认 1 |
| 校验位 | 无、奇校验、偶校验，默认无 |
| DTR / RTS | DTR 默认关闭，RTS 默认开启；仅在连接后生效，连续点击按 100ms 防抖，最终只发送一次 |
| 选择日志目录 | 打开系统文件夹选择框；选定后「保存日志」与工作流的「保存日志」动作均写入该目录 |
| 保存日志 | 将当前输出保存为 `Serial Debug 年-月-日 时分秒.txt`，直接写入已选目录；未选择目录时提示「未设置日志目录」 |
| 复制全部 | 将内存中的完整日志复制到剪贴板，包含输出区已滚动的部分 |
| 折叠工具栏 | 将工具栏收起为一条细边，鼠标移入时临时展开；再次点击恢复常驻 |
| ＋ 添加规则 | 新建一条工作流规则，见「工作流」 |

## 发送

在输入框中按回车或点击「发送」发送数据，未连接时发送按钮不可用。发送格式由输入框右侧的「文本 / HEX」选择器决定，与工具栏的「查看」设置相互独立。

文本模式遵循以下规则：

- 数据按 UTF-8 编码发送。
- `\r`、`\n`、`\t`、`\\` 解析为转义字符。
- 发送前按工具栏「行尾」设置追加行尾；转义与行尾相互独立，行尾始终追加一次。

HEX 模式遵循以下规则：

- 忽略空白与 `0x` 前缀，按两位一组解析，例如 `AA 55 0x01`。
- 十六进制字符数为奇数时提示「Hex长度必须为偶数」，包含非十六进制字符时提示「无效Hex: xx」；错误仅写入输出区，不发送数据。
- HEX 模式不追加行尾。

发送历史遵循以下规则：

- 每个分栏保留最近 50 条记录，连续重复的记录只保留一条。
- `↑` 将记录逐条回填至输入框；`↓` 打开历史列表并选中最新记录，再次按 `↓` 向下移动；在列表中按回车填入选中项，按 `Esc` 关闭列表。
- 发送历史随配置保存最近 20 条，重启后保留。

## 接收区

接收区按所选显示模式处理设备数据。文本模式使用 UTF-8 流式解码，多字节字符跨轮询分块时不会出现乱码；数据分块本身不产生换行，仅当收到 `\r\n`、`\n` 或单独的 `\r` 时换行。HEX 模式按字节显示，每行最多 192 个十六进制字符，首行带 `HEX:` 前缀。

滚动到顶部时，程序按 1000 行一批加载更早的缓冲内容。输出区的 DOM 行数存在上限，完整历史保存在内存缓冲中，缓冲预算为 8 MiB，超出后裁剪至一半；「保存日志」与「复制全部」均读取该缓冲。

前端读取不及时时，例如面板长时间隐藏或设备发送过快，后端接收缓冲达到 256 KiB 后丢弃最旧的数据，并在输出区提示丢弃的字节数。

## 日志与缓存

「清除内容」除清空显示内容外，还会清空输出区、终端画布与内存缓冲，并截断当前会话的磁盘缓存文件；该会话尚未写入内容时执行此操作不产生效果，也不报错。

串口打开后，只要产生收发数据，程序就将本次会话缓存到磁盘，每个会话一个文件，收发内容按 300ms 批量写入：

```
%APPDATA%\seahi-serial\log-cache\session-<年月日-时分秒毫秒>-<端口>.log
```

缓存目录遵循以下规则：

- 最多保留 10 个文件，创建新文件前删除最旧的文件。
- 单个文件达到 8 MiB 后停止写入，文件末尾保留一行终止标记，界面提示一次；正在写入的文件不会被删除。
- 目录总量达到 64 MiB 后从最旧的文件开始删除。
- 自动重连沿用同一个缓存文件，日志保持连续；会话结束时若文件仍为空，则删除该文件。

需要长期保存时，可在「更多设置」中点击「保存日志」另存；程序不会自动删除手动保存的文件。

## 断线重连

自动重连按钮默认关闭。开启后，读取数据出错时程序按以下顺序处理：

1. 关闭端口，按钮变为「等待接入」，端口下拉与发送按钮同时禁用。
2. 最多重连 10 次，间隔为 2 秒乘以尝试次数，最长 20 秒。
3. 连接成功后按钮恢复为「停止监控」；10 次均失败后恢复为「开始监控」，并结束当前会话缓存。

手动点击「停止监控」不会触发自动重连；自动重连放弃后，点击「开始监控」即为手动重连。重连过程不写入日志，输出区仅显示设备数据，进度通过按钮文字与端口状态点反映。

## 工作流

工作流规则位于「更多设置」中，点击「＋ 添加规则」新建，规则列表显示在工具栏下方。每条规则包含以下配置：

- 名称、启用开关、运行与停止按钮、折叠按钮和删除按钮。
- 匹配条件：字符串包含、正则表达式、精确字节(HEX)；一条规则可添加多条条件，全部满足时命中，跨轮询分块的数据同样参与匹配。
- 执行动作：发送数据（文本或 HEX，文本追加当前行尾）、切换信号（DTR 或 RTS，高或低电平）、保存日志（将收到的数据追加到所选日志目录的 `workflow_log.txt`）；动作按顺序执行，每个动作可设置延时，单位为毫秒。

规则上限为每个分栏 50 条，每条最多 8 个条件与 8 个动作；名称上限 64 字，条件值上限 512 字，动作数据上限 4096 字。

规则仅在监控期间检查。规则命中时，输出区写入一行 `[Auto] ...`，同一内容写入日志中心的 `workflow` 通道。在面板中点击「运行」即可启动规则；MCP 侧规则以停止状态创建，启动需调用 `serial_workflow_run` 并传入 `confirm:true`。
