# 终端模式

工具栏的终端按钮会把输出区切换成 xterm.js 画布。光标移动、清屏、颜色和全屏程序都由 xterm 处理，串口另一端的 `vim`、`top` 可以正常显示和操作。

## 直发与行缓冲

工具栏的「命令行缓冲」决定按键如何发送。串口分栏默认开启行缓冲，WSL 分栏默认关闭。

| | 直发（缓冲关闭） | 行缓冲（缓冲开启） |
|---|---|---|
| 敲字 | 每个按键立即发送 | 先在本地累积成一行 |
| 回车 | 只发送 `CR (0x0D)` | 整行连同工具栏的行尾一起发送 |
| 退格 | 发送 `0x7F` | 只在本地擦除，不发给设备 |
| 方向键 | 原样发送 `ESC[A/B/C/D` | 在本地编辑当前行，上下键翻历史 |
| 回显 | 由设备 tty 负责 | 本地回显一份 |
| Tab | 发送 `HT (0x09)` | 发送 `HT (0x09)` |
| 适用场景 | Linux 控制台、shell | AT 指令、串口协议 |

行缓冲适合 AT 指令：逐键发送、回车只给 `\r`、退格 `0x7F` 被模组当作无效字节，这三点都会让 AT 命令出错。行缓冲把整行攒好再补上行尾，模组才能正确识别。

设备如果开了回显（`ATE1`），输入内容会显示两份，这是正常现象。关闭设备回显（`ATE0`）即可。

## 终端模式下的行为

- 不做本地 Tab 补全，补全交给设备上的 shell。
- 进入终端模式时自动向设备发送一个回车，设备会重新打印提示符。未连接时不发送。
- 不回放普通输出区的旧日志。退出终端模式后，普通输出区仍保留完整记录。
- 「显示行号」「时间戳」「消息回显」会置灰，因为它们只作用于普通输出视图。置灰只改变外观，不会修改你原来的开关状态，退出终端模式后照旧生效。
- 16 色 ANSI 调色板跟随当前主题，和普通输出区使用同一套颜色定义。
- 关闭分栏或重新打开程序后，终端内容从空白开始，不会保存历史。

## 普通输出区不主动上色

普通输出区只解析日志自带的 16 色 ANSI 转义（30–37、90–97 和粗体）。256 色和真彩色按纯文本显示。颜色能力只存在于终端模式。

## 命令记录

逐字符记录会让日志难以阅读，所以终端模式只记录命令级操作：

- 按回车提交时记录一条，粘贴时记录一条，写入 `serial:<分栏>:tx` 通道，来源标记为 `ui`。
- 用 `↑` 从设备侧 readline 历史里取出的命令，本机看不到原始内容，这种情况宁可不记。
