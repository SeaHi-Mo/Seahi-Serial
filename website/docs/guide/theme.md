# 主题

顶栏的「主题风格」下拉和深浅色开关用来切换界面配色。

提供 6 种风格：默认、浮世绘彩、诗意东方、水墨丹青、桃之夭夭、金风玉露。每种风格都有浅色和深色两套，共 12 套主题。

切换主题后，普通输出区、终端模式、侧边栏、按钮等界面会一起更新。终端里的 16 色 ANSI 调色板也取自当前主题，和普通输出区使用同一份颜色定义，所以同一段彩色日志在两种视图里颜色一致。

主题选择会写入配置文件，下次启动时沿用。
