# WSL 端口映射

顶栏的「WSL 端口映射」把 USB 串口映射进 WSL，之后可以在 WSL 里直接访问串口设备。

## 快速启动 WSL

WSL 面板顶部会列出本机所有发行版，名称来自 `wsl --list --verbose` 的真实结果，不需要先手动打开 Windows Terminal。

- 停止状态的卡片显示「启动」；点一下会启动该发行版。
- 运行中的卡片显示「关闭」和运行时长（uptime）；点「关闭」会停止发行版。
- 卡片右侧的终端图标用 Windows Terminal 打开这个发行版的终端。
- 有多个发行版时，用「映射到」下拉选择要把设备映射到哪个发行版；留空表示默认发行版。
- WSL 没有运行时，设备映射和 WSL 分栏的「开始监控」不可用，先启动发行版。

## 映射设备

- 依赖 [usbipd-win](https://github.com/dorssel/usbipd-win)，安装包里已经包含。绑定和映射需要管理员权限。
- 支持自动映射和手动绑定。绑定过程中 Windows 会弹出授权窗口，需要在系统弹框上确认。
- 映射前如果目标 COM 口正在某个分栏里监控，程序会先停止该分栏的监控，再执行映射。
- 映射完成后，WSL 里会出现新的 `/dev/ttyUSB*` 或 `/dev/ttyACM*`。

## 映射之后：在 WSL 分栏里调试

映射成功后，WSL 分栏就是这台设备的串口调试入口，不需要再开 Windows 侧的串口监视器。

1. 先确认发行版在运行（见上面的「快速启动 WSL」）。WSL 停止时，分栏会显示为不可用。
2. 在 WSL 设备列表里勾选目标设备的「映射」，第一次会弹管理员授权；授权后等待状态变成已映射。
3. 设备行会显示它对应的 WSL 路径，例如 `/dev/ttyUSB0`。映射刚完成时路径可能要等几秒，列表会自动刷新。
4. 回到下方的 WSL 分栏，点端口下拉框旁的刷新按钮，选择这个 `/dev/ttyUSB*` 或 `/dev/ttyACM*` 端口。
5. 设置波特率、行尾和查看模式，点「开始监控」。之后的收发与普通串口分栏一致：文本/HEX 发送、发送历史、日志缓存都能用。
6. 需要交互式终端时，打开分栏的终端模式。WSL 分栏默认是直发模式，按键原样送给 Linux 侧的设备；如果设备要整行命令，再打开命令行缓冲。
7. 掉线时界面显示「等待接入」；检查设备是否还插着、映射是否还在，必要的话重新点映射并刷新端口。

如果 WSL 分栏的端口下拉里一直为空：

- 确认发行版处于运行状态，而不是只启动了 Windows Terminal 窗口。
- 回 WSL 面板看目标设备的映射状态和 WSL 路径是否已经出现。
- 点 WSL 分栏的刷新按钮；也可以先取消映射再重新映射。
- 在 WSL 里执行 `ls /dev/ttyUSB* /dev/ttyACM*` 确认设备节点是否存在。
